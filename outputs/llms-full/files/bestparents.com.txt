## API Documentation

### Complete Sitemap API

Get the full site structure with all URLs and markdown endpoints:

```bash
GET https://www.bestparents.com/api/markdown/sitemap
```

Returns JSON with:
- All landing pages (5166 total)
- All courses (514+ total)
- All blog posts (118 total)
- All static pages
- Markdown API URLs for every page

### Markdown Endpoints

#### 1. Page Markdown API

```
GET /api/markdown/page/[...path]?lang=[en|es|tr|de|fr|pt|it|zh|ar]
```

**Handles**:
- Homepage (`index`)
- Landing pages (e.g., `uk-summer-camps`)
- Static pages (e.g., `about`, `contact`, `terms`)
- Courses listing (`courses`)

**Response**:
```json
{
  "title": "Page Title",
  "description": "Meta description",
  "url": "https://www.bestparents.com/page",
  "language": "en",
  "type": "landing-page|static-page|homepage|courses-listing",
  "markdown": "# Page Title\n\n..."
}
```

#### 2. Course Markdown API

```
GET /api/markdown/course/[...path]?lang=[en|es|tr|de|fr|pt|it|zh|ar]
```

**Path Format**: `[landing-page-slug]/[course-slug]`

**Example**: `/api/markdown/course/uk-summer-camps/oxford-royale-engineering?lang=en`

**Response**:
```json
{
  "title": "Course Title",
  "description": "Course description",
  "url": "https://www.bestparents.com/landing/course",
  "language": "en",
  "type": "course",
  "slug": "course-slug",
  "institution": "Institution Name",
  "location": "City, Country",
  "price": {
    "amount": 2998,
    "currency": "GBP",
    "period": "week"
  },
  "markdown": "# Course Title\n\n..."
}
```

#### 3. Blog Markdown API

```
GET /api/markdown/blog/[slug]?lang=[en|es|tr|de|fr|pt|it|zh|ar]
```

**Example**: `/api/markdown/blog/academic-camps?lang=en`

**Response**:
```json
{
  "title": "Blog Post Title",
  "author": "Author Name",
  "date": "January 5, 2025",
  "description": "Post description",
  "url": "https://www.bestparents.com/blog/slug",
  "language": "en",
  "type": "blog-post",
  "slug": "slug",
  "markdown": "# Blog Title\n\n..."
}
```

### Content Negotiation via Accept Header

Request any page with `Accept: text/markdown` header to automatically receive markdown response:

```bash
# Automatic routing to markdown API
curl -H "Accept: text/markdown" https://www.bestparents.com/uk-summer-camps
curl -H "Accept: text/markdown" https://www.bestparents.com/blog/academic-camps
curl -H "Accept: text/markdown" https://www.bestparents.com/uk-summer-camps/oxford-royale-engineering
```

The middleware automatically detects the content type and routes to the appropriate markdown API endpoint.

### Caching

All markdown API responses include cache headers:
```
Cache-Control: public, max-age=3600
```

Content is cached for 1 hour (3600 seconds).

## Usage Examples

### For AI Agents

```python
import requests

# Get sitemap
sitemap = requests.get("https://www.bestparents.com/api/markdown/sitemap").json()

# Get a landing page
page = requests.get(
    "https://www.bestparents.com/api/markdown/page/uk-summer-camps",
    params={"lang": "en"}
).json()

# Get course details
course = requests.get(
    "https://www.bestparents.com/api/markdown/course/uk-summer-camps/oxford-royale-engineering",
    params={"lang": "en"}
).json()

# Use Accept header
response = requests.get(
    "https://www.bestparents.com/uk-summer-camps",
    headers={"Accept": "text/markdown"}
)
```
