# Graph Indexing and Adjacency Traversal Engines — Facts
- Compressed Sparse Row (CSR) and Compressed Sparse Column (CSC) formats provide static contiguous memory layouts with O(1) neighbor lookups and optimal cache-locality for analytical traversals, but require O(V+E) rebuilding overhead on dynamic graph updates. — https://epubs.siam.org/doi/10.1137/1.9781611972887.ch2
- Dynamic graph engines utilize chunked adjacency lists, differential updates, or LSM-tree-backed key-value stores (e.g. RocksDB in Memgraph and NebulaGraph) to balance write amplification with neighbor iteration throughput. — https://memgraph.com/docs/internals/storage-memory
- Vector-graph hybrid indexes integrate vector quantization (e.g. HNSW, IVF-PQ) into graph node storage, allowing simultaneous euclidean/cosine vector similarity filtering and topological neighbor expansion in a single scan. — https://arxiv.org/abs/1603.09320
