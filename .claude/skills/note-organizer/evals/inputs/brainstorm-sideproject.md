# App brainstorm
Core concept: short-lived trail-condition reports, not a permanent guidebook.
Reports expire by type; this is the differentiator.
MVP: iOS only.
MVP: three report types: mud, snow and closure.
MVP launch in Seattle because I can seed reports on local trails myself.
MVP: use a device ID, no accounts.
Cold start: seed useful reports before launch.
Question: would scraping public seed data be legal? Gray area.
Question: liability if a closure report is wrong?
Revenue idea: paid alerts after the MVP proves useful; no price decided.
Report-expiry by type is the differentiator, not a generic map.
Gamification is doubtful; park it.
Offline maps rejected as scope creep.
Name idea: freshtracks, but I worry that name is already taken.
