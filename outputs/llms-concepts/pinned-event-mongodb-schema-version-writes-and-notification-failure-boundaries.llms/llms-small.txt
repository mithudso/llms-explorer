## Definitions

- [statement] The read-check-replace sequence is not a database compare-and-swap on the version: `Get` reads by `_id`, while `p.collection.ReplaceOne` filters only by `_id`. Inference from those predicates: a concurrent writer can replace the record between the check and replacement, so this method alone does not establish atomic monotonic version enforcement. (low confidence) — https://raw.githubusercontent.com/rbaliyan/event-mongodb/ca444aedec31e7e959c0932a8f7577c15312f37e/schema/mongodb.go

## Problems, failure modes and limitations

- [statement] In the pinned implementation, `Set` calls `schema.Validate()` before checking whether the provider is closed. It then calls `p.Get(ctx, schema.Name)` and returns its error. The downgrade predicate is `existing != nil && schema.Version < existing.Version`; equal versions are permitted. (medium confidence) — https://raw.githubusercontent.com/rbaliyan/event-mongodb/ca444aedec31e7e959c0932a8f7577c15312f37e/schema/mongodb.go · keywords: Pinned event-mongodb schema version writes and notification failure boundaries · also: https://raw.githubusercontent.com/rbaliyan/event-mongodb/ca444aedec31e7e959c0932a8f7577c15312f37e/schema/mongodb_test.go
- [statement] After the version check, `Set` converts the supplied schema, assigns `m.UpdatedAt` from `time.Now()`, assigns `m.CreatedAt` for a new record or preserves the existing value, and calls `p.collection.ReplaceOne` with only `_id` in the filter and `options.Replace().SetUpsert(true)`. A replacement error returns before notification. (low confidence) — https://raw.githubusercontent.com/rbaliyan/event-mongodb/ca444aedec31e7e959c0932a8f7577c15312f37e/schema/mongodb.go
- [statement] After a successful replacement, Set constructs a SchemaChangeEvent from Name, Version and the same timestamp, attempts local watcher sends under an RLock using select with a default branch, releases the lock, and invokes a non-nil publisher. A channel that cannot accept the send loses that notification without an error from this loop. (low confidence) — https://raw.githubusercontent.com/rbaliyan/event-mongodb/ca444aedec31e7e959c0932a8f7577c15312f37e/schema/mongodb.go
- [statement] A publisher error is returned directly from Set after the replacement and local watcher-send attempts; the method contains no rollback, retry or persisted pending-notification operation for that error path. This is a source-level control-flow observation, not an executed failure test. ## Comparisons and alternatives

- [statement] `Delete` checks the closed flag and calls `p.collection.DeleteOne` using `_id`; it wraps database errors and otherwise returns nil without inspecting the deletion count. Unlike `Set`, its body does not send to local watchers or invoke the publisher. (low confidence) — https://raw.githubusercontent.com/rbaliyan/event-mongodb/ca444aedec31e7e959c0932a8f7577c15312f37e/schema/mongodb.go
