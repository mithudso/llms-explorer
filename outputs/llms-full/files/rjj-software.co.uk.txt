## Company Overview

RJJ Software Ltd is a Leeds-based strategic technology consultancy specialising in technology leadership and advisory services. Founded in 2018, the company operates with a unique approach grounded in compassion for clients and their customers, emphasizing understanding problems deeply to create innovative, perfectly-fitted solutions.

### Core Mission

The company's mission centers on realising the digital potential of clients through strategic technology leadership. By sharing deep compassion for clients and their customers, RJJ Software ensures a deeper understanding of challenges and creates innovative solutions that fit perfectly.

### Leadership

Led by Jamie Taylor, Fractional Chief Technology Officer (CTO) and technology consultant with almost 20 years of experience helping businesses make better technology decisions. Jamie has transitioned from hands-on development consulting to strategic technology advisory. A former Microsoft Most Valuable Professional (MVP) for Developer Technologies (four consecutive years), Jamie created and maintains OwaspHeaders.Core (over 1.9 million NuGet downloads, version 10.4.0 released May 2026) and hosts The Modern .NET Show podcast (196 episodes across 8 seasons since 2018, around 14,000 monthly listens, and aggregate listens of over 1.3 million across all platforms). He volunteers as a facilitator at Andy's Man Club, supporting men's mental health initiatives.

## Open Source Contributions

### OwaspHeaders.Core

**Project Overview:**
OwaspHeaders.Core is a free, open-source NuGet package designed for ASP.NET Core applications that provides easy-to-use middleware for injecting OWASP-recommended HTTP security headers.

**Key Features:**
- **Easy Integration**: Single-line middleware addition to ASP.NET Core pipeline
- **Comprehensive Security**: All OWASP-recommended HTTP headers included
- **Regular Updates**: Maintained with latest security recommendations
- **Documentation**: Comprehensive usage examples and configuration guides

**Technical Implementation:**
```csharp
// Installation
dotnet add package OwaspHeaders.Core

// Usage in Startup.cs or Program.cs
app.UseSecureHeadersMiddleware();
```

**Security Headers Included:**
- Content Security Policy (CSP)
- X-Frame-Options
- X-Content-Type-Options
- Strict-Transport-Security
- Referrer-Policy
- Permissions-Policy

**Impact Metrics:**
- Over 1.9 million NuGet package downloads (averaging around 3,400 downloads per day)
- Latest version 10.4.0 released May 2026, targeting .NET 8.0 and higher with no external dependencies
- Used by thousands of ASP.NET Core applications worldwide
- Regular security audits and community contributions
- Comprehensive test suite with strong code coverage

## Case Studies

A current list of all public case studies is available at https://rjj-software.co.uk/case-studies/. The five highlighted below represent the headline outcomes most worth citing.

### AI Adoption at Ligentia (June 2025 - May 2026, concluded)

**Project Overview:**
Twelve-month engagement with Ligentia, a globally distributed logistics business, to enable their engineering team to ship higher-quality features faster through Artificial Intelligence (AI) adoption.

**Challenge:**
A sceptical engineering team, distributed globally, with existing DevOps Research and Assessment (DORA) dashboards already feeding into reporting calls with project owners. The brief, delivered directly by Chief Information Officer Boris Rabkin, was to lift feature delivery without compromising quality.

**Solution:**
- Tooling evaluation and selection (resulting in Claude and Claude Code deployment)
- Pull request review pipeline with AI doing the first-pass review
- Workshops and embedded delivery to build team confidence and fluency
- Programme-of-change framing rather than a tooling rollout

**Results:**
- 75% improvement in feature delivery measured through Ligentia's own DORA dashboards, with a defensible baseline from before the engagement began and consistent methodology throughout
- Daily use of Claude or Claude Code across most of the globally distributed company
- AI fluency programme adopted company-wide

**Full case study:** https://rjj-software.co.uk/case-studies/higher-quality-shipped-faster-ai-adoption-at-ligentia/

### Strategic Technology Assessment saving £25,000 (2025)

**Project Overview:**
Hardware-refresh assessment for a small business facing the Windows 10 end-of-life deadline.

**Challenge:**
Their entire fleet of computers had been flagged as unable to upgrade to Windows 11, with less than 40 days before Microsoft would cease security updates. The default vendor response would have been an unbudgeted hardware replacement costing approximately £25,000.

**Solution:**
- Strategic technology assessment of the existing hardware
- Identification of hidden capabilities in current machines that vendor scans had missed
- Targeted upgrade path rather than full replacement

**Results:**
- Avoided £25,000 in unnecessary capital expenditure
- Existing hardware retained and brought into Windows 11 compliance
- Security maintained without rushed procurement

**Full case study:** https://rjj-software.co.uk/case-studies/how-strategic-technology-assessment-saved-a-small-business-25000/

### Database modernisation for a Formula 1 team

**Project Overview:**
Entity Framework Core upgrade and database communication redesign for a Formula 1 racing team.

**Challenge:**
Legacy database communication code that needed to keep pace with modern Entity Framework Core releases, with limited tolerance for regressions in a competitive environment.

**Solution:**
- Entity Framework Core upgrade to the current release
- Database communication architecture redesign
- Test coverage improvements across functional and non-functional requirements
- Closer working relationship with the team's own engineers to embed the changes

**Results:**
- Access to current database communication technology with improved performance and scalability characteristics
- Reduced risk of future regressions through expanded test coverage
- A platform the team could continue to evolve confidently

**Full case study:** https://rjj-software.co.uk/case-studies/optimizing-racing-technology-enhancing-database-communication-with-an-entity-framework-core-upgrade/

### Reporting platform for Bossie Hurley / Straight Path Solutions (2026)

**Project Overview:**
Cloud-native reporting service built for Bossie Hurley's end client, Straight Path Solutions, where new report types ship through configuration rather than deployments.

**Challenge:**
Reporting platforms typically tie new report types to release cycles. Bossie Hurley wanted report definitions to live in configuration so the team could deliver new types without a deployment dance.

**Solution:**
- Cloud-native reporting service generating scheduled PDF reports
- Report definitions held in configuration, not code
- Daily and weekly cadences feeding Straight Path's own customers

**Results:**
- New report types shippable without a deployment
- Production cadence maintained across daily and weekly reports

**Full case study:** https://rjj-software.co.uk/case-studies/shipping-reports-without-shipping-software-building-a-data-driven-reporting-platform/

### Scientific Data Analysis Platform (Sage Texti)

**Project Overview:**
Collaboration with Sage Publishing on Sage Texti, a research platform that lets researchers extract insights from scientific paper corpora without requiring data science expertise.

**Challenge:**
Sage Publishing wanted to democratise advanced data analysis for researchers without a software background, while protecting research data and keeping the platform scalable.

**Solution:**
- Intuitive web application with a drag-and-drop What You See Is What You Get (WYSIWYG) workflow editor
- Pre-defined data science actions composable into custom analyses
- Containerised execution environments for scalability and isolation
- Ephemeral containers to prioritise data privacy
- Weekly collaboration cycle with Dr. Daniela Duca, Sage Publishing's senior project manager

**Results:**
- Sage Texti launched as a service after an intensive three-month Minimum Viable Product (MVP) stage
- Researchers able to design custom analyses without writing Python directly
- Data privacy maintained through ephemeral containerised execution

**Full case study:** https://rjj-software.co.uk/case-studies/sage-texti-revolutionizing-scientific-data-analysis/
