## Purpose and reader

Help developers and technical users build AI workflows they can inspect and reuse. The site's two core strengths are practical workflow guidance and open tools backed by inspectable project work. The knowledge library supports those strengths. A visitor should leave with a checked result or a clear next step.

This positioning is a working editorial choice based on the existing material. The audience question is pending; no analytics evidence has been used to claim this is the current readership.

## Evidence from the audit

The deployed homepage led with agent formats and corpus counts, offered eight primary sections plus utilities, and was about 6,403 CSS pixels tall at a 1,440px desktop viewport. It gave multiple products equal prominence before its strongest original writing.

The repository contains 33 blog articles, 14 examples, 16 reference documents and 23 skill pages. The tree snapshot has 684 nodes, 440 with corresponding public concept packs, and 244 without them. The 459 concept JSON files include 19 not represented by tree nodes. Do not count those as current published topic routes.

The existing built sitemap had 792 URLs. The refocused build has 551 public URLs: missing references and the unsupported comparison are excluded, and four new authored pages are included. Empty routes such as `/tree/bayes-theorem/` presented a researched label and no published facts. Mirrored source pages and directory rows already used noindex. These observations are potential quality problems; they do not reveal Google's actual rejection classifier or identify its specific cause.

The vendored directory was refreshed offline: 164 scorable files from 992 fetched files and 1,231 known entries. Its public scope and reference now match those files. This refresh did not run indexing or inference.

The strongest original feature is `/blog/what-docs-llms-files-and-indexes-actually-save/`: 256 recorded agent runs, raw results, methods, correctness checks and explicit negative findings. Architecture and implementation reports are useful too, but they must not be presented as measured effect sizes.

The local-model comparison article lacked matching public evidence for its comparative throughput ranges. The included Qwen2-beta transcript did not validate those ranges. The refocus preserves the material, adds an evidence-gap notice and a dated correction in HTML and Markdown, withdraws the unsupported comparative conclusions and deployment advice, and excludes it from Search and feature promotion. This is not a claim that every figure is false.

## Search and advertising rules

Keep every topic URL working. Topic pages are indexable only when their actual pack has a nonempty summary and at least one nonempty source-linked fact. This is a content-availability gate, not an accuracy audit or a certification of substantial value. Missing and incomplete references show truthful topic labels and noindex, follow. The sitemap reads that metadata automatically.

Raw Markdown twins, family files and downloads are fetchable but carry noindex response headers. The authored HTML pages remain the public Search surface.

Ads default to off. AdSense ownership uses the documented google-adsense-account meta tag. A later page-level ad opt-in needs a content assessment and an appropriate consent configuration. Preserve the stricter CSP and absence of third-party tags on account/key/playground routes. No AdSense review request has been sent.
