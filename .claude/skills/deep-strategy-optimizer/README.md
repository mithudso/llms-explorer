# Deep Strategy Optimizer

Audit trading strategies, indicators, and backtests using the installed `SKILL.md`, the method catalogue, and the applicable pass definitions in `references/`. This bundle contains 273 auditable methods across nine families, plus descriptive metrics and duplicate mappings. Review the target project’s own evidence, tests, tools and operating constraints. Project-specific examples are illustrative; they are not prerequisites or measurements of the current target. Research output is not investment advice; simulation only.
