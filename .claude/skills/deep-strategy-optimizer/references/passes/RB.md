# RB — Robustness and sensitivity

Question this family answers: Does the number survive small, defensible changes?

23 passes. Each row is one pass: one evaluation method, one check, one fix. `Fails →` is the severity the finding carries when the check fails (see SKILL.md § Severity). Sources for every method are in `../evaluation-methods.md`.
