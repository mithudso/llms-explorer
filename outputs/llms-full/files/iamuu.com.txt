- **PDF features**: Merge, split, convert to/from Office, compress, encrypt/decrypt, OCR, sign, redact, annotate

## Common Workflows (Usage Examples)

### Compress a JPG Image
1. Go to https://www.iamuu.com/en/image/compress/
2. Upload a JPG/PNG/WEBP image (up to 50MB free)
3. Adjust quality slider (lower = smaller file)
4. Preview compressed result in real-time
5. Click Download to save the compressed image

### Merge Multiple PDF Files
1. Go to https://www.iamuu.com/en/pdf/merge/
2. Upload 2+ PDF files (drag to reorder)
3. Click Merge PDFs
4. Download the combined PDF

### Convert PDF to Word (DOCX)
1. Go to https://www.iamuu.com/en/pdf/to-word/
2. Upload a PDF file
3. Processing starts automatically
4. Download the DOCX file (editable in Microsoft Word / Google Docs)

### Convert Image Formats (JPG to PNG, PNG to WebP, etc.)
1. Go to https://www.iamuu.com/en/image/convert/
2. Upload an image file
3. Select target format from dropdown (JPG, PNG, WEBP, GIF, BMP, TIFF, ICO, PDF)
4. Optional: adjust DPI, color mode (RGB/CMYK), background color
5. Click Convert and Download

### Remove Image Background (AI)
1. Go to https://www.iamuu.com/en/image/bg-remove-ai/
2. Upload a photo with clear subject
3. AI automatically detects and removes background
4. Download result as PNG with transparent background

### Batch Compress PDFs
1. Go to https://www.iamuu.com/en/pdf/batch-compress/
2. Upload multiple PDF files
3. Select compression level (recommended/maximum)
4. Download ZIP containing all compressed PDFs

### Split PDF by Pages
1. Go to https://www.iamuu.com/en/pdf/split/
2. Upload a PDF file
3. Select page ranges to extract (e.g., "1-3,5,7-9")
4. Single range → download PDF directly; multiple ranges → download ZIP
