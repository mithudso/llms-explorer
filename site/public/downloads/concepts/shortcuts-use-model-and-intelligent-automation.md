# Shortcuts Use Model and intelligent automation

> Source-anchored research for Shortcuts Use Model and intelligent automation. Run status: COMPLETED.

## How it works

- The current Shortcuts guide says model input can include variables, previous action outputs, calendar events, reminders, and photos. It says responses are optimized for the next action by default, with an Output menu for choosing a format. WWDC25 documents Text, Dictionary, and Content from your apps outputs; it shows the runtime producing a Boolean when an If action requires one and Follow Up letting a user refine the response before it reaches the next action. (high confidence) (verified as of 2026-09-17) — [source](https://support.apple.com/en-us/guide/shortcuts/tpg3vrvwmclv/ios)
- Independent hands-on reports show Use Model working well as a task-specific transformation but needing review: WIRED’s event and reminder extraction examples required fine-tuning and sometimes got details wrong, while 9to5Mac reported knowledge and interface limits when judging the action as a full-time chatbot. These reports support adding a preview or confirmation step before a shortcut commits extracted model output. (medium confidence) — [source](https://www.wired.com/story/apple-shortcuts-just-got-a-lot-better/)
- When Use Model selects Extension Model, Apple identifies ChatGPT as the model. Apple's privacy page says the ChatGPT extension is off by default and must be enabled before sending information; a request, attachments, and limited request metadata such as time zone, country, device type, language, and feature may be sent to ChatGPT. Apple's public page does not specify whether each Shortcuts run triggers a separate confirmation. (high confidence) (verified as of 2026-09-14) — [source](https://support.apple.com/en-us/guide/shortcuts/tpg3vrvwmclv/ios)

## How-to and procedures

- Use Model can take variables and outputs from prior actions, calendar events, reminders, photos, and other input. Follow Up lets a person refine the prompt before the final response passes to the next action. Apple says output is optimized for the following action by default and can be selected in the Output menu; MacStories independently demonstrated passing third-party app entities through the action as structured inputs and outputs. (high confidence) (verified as of 2026-09-17) — [source](https://support.apple.com/en-us/guide/shortcuts/tpg3vrvwmclv/ios)

## Problems, failure modes and limitations

- Apple states that server-side AFM 3 Cloud models in Shortcuts have daily usage limits. The limit can vary with the feature, request complexity, system demand, system policies, and other factors; Apple does not give a fixed quota in the current support pages. (high confidence) (verified as of 2026-10-22) — [source](https://support.apple.com/en-us/121115)
- In a June 25, 2025 hands-on report, Six Colors found that Use Model sometimes ignored requested length and quotation-format constraints and sometimes mishandled extracted receipt fields. This supports validating exact model-generated values before later actions rely on them; it does not establish error rates for current OS 27 releases. (low confidence) (verified as of 2025-06-25) — [source](https://sixcolors.com/post/2025/06/experimenting-with-apples-ai-models-inside-shortcuts/)

## Facts and statements

- Apple presents Use Model as a Shortcuts action that accepts a prompt and can feed its response to a following action. Its guide lists variables and earlier action outputs, along with calendar events, reminders, and photos, as possible model inputs. WIRED’s hands-on example extracts an event title, time, and location from unstructured invitation text before a calendar action; Tom’s Guide demonstrates passing a Safari webpage into Use Model and sending its response to Notes. (high confidence) — [source](https://support.apple.com/en-us/guide/shortcuts/tpg3vrvwmclv/ios)
- Apple’s iPhone and iPad Shortcuts guide lists On-Device, Cloud, Cloud Pro, and Extension Model (ChatGPT). On-Device works without a network connection; Cloud and Cloud Pro use Private Cloud Compute; Cloud Pro has extended context; and Cloud or Cloud Pro can use the optional Broad World Knowledge setting for current events and real-world context. (high confidence) (verified as of 2026-09-17) — [source](https://support.apple.com/en-us/guide/shortcuts/tpg3vrvwmclv/ios)
- Apple’s September 29, 2026 OS 27 feature page says Use Model supports enhanced Apple Intelligence models and can retrieve up-to-date information from the web. This confirms the capability as a released OS 27 feature, while the Use Model guide documents Broad World Knowledge as an optional Cloud and Cloud Pro setting. (high confidence) (verified as of 2026-09-29) — [source](https://support.apple.com/en-us/149045)
- Taken together, Apple’s user guide and developer sessions indicate that basic Use Model availability is a Shortcuts feature, while app-specific model context is a separate App Intents integration: developers expose their app’s entities and properties, which Shortcuts serializes into JSON for the model. WWDC26’s transcript inspector lets developers inspect the exact data passed to the model. This distinction is an inference from Apple’s user and developer documentation. (medium confidence) — [source](https://support.apple.com/en-us/guide/shortcuts/tpg3vrvwmclv/ios)
- Apple’s OS 27 update page, published 2026-09-29, says server-side Apple Intelligence features including AFM 3 Cloud models in Shortcuts have daily usage limits. Apple says limits can vary by feature, request complexity, system demand, system policy, and other factors, and expanded access will be available for a fee. The guide and update page publish no numerical quota or reset schedule. (high confidence) (verified as of 2026-09-29) — [source](https://support.apple.com/en-us/149045)
- Apple’s Shortcuts guide maps Extension Model to ChatGPT. Apple’s ChatGPT Extension & Privacy page, dated 2026-09-14, says the extension is off by default, must be enabled before information is sent, and can be disabled. That page describes confirmation behavior for Siri and feature-by-feature choice for some other Apple Intelligence features, but does not say whether Use Model prompts for confirmation on each shortcut run. (high confidence) (verified as of 2026-09-14) — [source](https://support.apple.com/en-us/guide/shortcuts/tpg3vrvwmclv/ios)
- As of 2026-10-23, Reddit users reported a Cloud Pro Unavailable response to a simple request, near-identical On-Device outputs despite prior-output context, and failures in a particular translation shortcut using Apple’s Use Model action. The Cloud Pro reporter later said replacing an expired AdGuard DNS certificate fixed the issue. The translation-shortcut reporter said switching to the ChatGPT app’s action worked, while being slower. These single-user reports are anecdotal and do not establish prevalence or an OS-wide defect. (low confidence) (verified as of 2026-10-23) — [source](https://www.reddit.com/r/shortcuts/comments/1pwdo8o/chatgpt_shortcuts_dont_work_in_some_situations/)
- Apple's current Shortcuts guide lists On-Device, Cloud, Cloud Pro, and Extension Model (ChatGPT). On-Device handles simple requests without a network connection; Cloud and Cloud Pro use Private Cloud Compute, and Cloud Pro has extended context. Apple's feature matrix lists model use in Shortcuts on iPhone, iPad, Mac, and Apple Vision Pro, while the detailed guide covers iPhone and iPad. (high confidence) (verified as of 2026-10-22) — [source](https://support.apple.com/en-us/guide/shortcuts/tpg3vrvwmclv/ios)
- For Cloud and Cloud Pro, the Shortcuts guide offers a Broad World Knowledge option for current events and real-world context. Apple's OS 27 feature notes also describe Use Model as able to retrieve up-to-date information from the web. (high confidence) (verified as of 2026-09-29) — [source](https://support.apple.com/en-us/guide/shortcuts/tpg3vrvwmclv/ios)
