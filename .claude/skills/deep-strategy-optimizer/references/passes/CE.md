# CE — Cost and execution realism

Question this family answers: Would the number survive real fills and fees?

45 passes. Each row is one pass: one evaluation method, one check, one fix. `Fails →` is the severity the finding carries when the check fails (see SKILL.md § Severity). Sources for every method are in `../evaluation-methods.md`.
