## Problems, failure modes and limitations

- [statement] TransactionalStore embeds Store and requires IsDuplicateTx(ctx context.Context, tx any, messageID string) (bool, error) and MarkProcessedTx(ctx context.Context, tx any, messageID string) error. Its transaction-object parameter is part of each required method signature. (low confidence) — https://raw.githubusercontent.com/rbaliyan/event/b112463682d44b0e57d8545e3cdf5d51e112e914/idempotency/store.go
- [statement] The Handle method of TransactionalHandler computes a key and calls h.txManager.Execute with the outer ctx. Inside its transaction callback it passes that captured ctx and the callback tx to IsDuplicateTx, the user handler and MarkProcessedTx. A duplicate-check error returns before user handling; a duplicate skips user handling and marking; a user-handler error returns before marking. Otherwise the callback returns the marker result. (low confidence) — https://raw.githubusercontent.com/rbaliyan/event/b112463682d44b0e57d8545e3cdf5d51e112e914/transaction/handler.go
