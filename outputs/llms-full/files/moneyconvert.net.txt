# MoneyConvert.net (Full)
> MoneyConvert.net is a multilingual, clarity-first currency conversion and reference site. It serves user-facing pages (converters, currency pages, charts) and public JSON endpoints used by the UI. English is the default locale (no URL prefix); other locales live under `/{lang}/…`.
This file is intended for LLMs and agents that need an accurate mental model of how MoneyConvert works, which URLs are canonical, and how to retrieve live numeric data.
## What the site provides
- Currency pair converters with live mid-market rates, optional `amount` parameter, and rich explanatory content.
- Currency reference pages (per currency code) and exchange-rate listings.
- Historical chart pages and a chart JSON endpoint.
- A public intraday JSON endpoint used for live rates.
Disclaimer
- Rates are informational only; do not frame as financial advice.
- Mid-market rates are vendor-neutral; if asked for bank/transfer rates, clarify that those differ.
Data freshness
- Live/intraday rates are typically refreshed every 1–10 minutes (may be edge cached).
## Localization model (critical for navigation and deduplication)
- Default locale: English (`en`). English URLs typically have no language prefix.
  - Example: https://moneyconvert.net/converter/
- Non-default locales use a required path prefix: https://moneyconvert.net/{lang}/…
  - Example: https://moneyconvert.net/uk/converter/
Canonical + hreflang
- Pages generate a canonical URL and `rel="alternate" hreflang=…` links.
- When you need “the one true URL” for deduplication, follow the canonical link.
- When answering in a specific language, prefer the locale-prefixed URL if it exists (and still confirm canonical/hreflang).
## Canonical URL rules you should follow
General
- Prefer URLs without query strings unless the query is explicitly canonical.
- Remove tracking params (`utm_*`, `gclid`, etc.) when citing.
Converter pair pages
- Primary pattern: `/converter/{base}-{quote}/` (lowercase currency codes).
  - Example: https://moneyconvert.net/converter/usd-eur/
- Optional amount: `?amount=…`
  - Amount must be a canonical positive number string.
  - Site validates `amount` strictly (no commas, no spaces, no leading zeros, no “0”, no “1.0”).
  - Examples of valid strings: `3`, `42`, `1.5`, `0.01`.
  - Examples of invalid strings: `0`, `01`, `1.`, `.5`, `1.0`, `1,000`, ` 10 `.
- Important: even if `?amount=…` is accepted, the canonical URL may still be the base pair page without the query string unless the amount is “approved” by the site’s suggested-amount rules. So:
  - Use `?amount=` for user intent (conversion for a specific amount).
  - Use the canonical URL when you need a single stable citation.
Legacy redirects
- Old converter format `/{base}/{amount}-to-{quote}` 301-redirects to `/converter/{base}-{quote}/?amount={amount}`.
- If `amount=1`, redirects to the base pair page without the query string.
## Public JSON APIs (preferred source for live numbers)
All endpoints below are under `https://moneyconvert.net/api/public/…`.
### Intraday rates
- Endpoint: `/api/public/intraday`
- Purpose: live-ish intraday snapshot used by the converter UI.
- Base currency is USD.
- Cache: edge cached (typically 1–10 minutes). Treat as near-real-time, not tick-by-tick.
PATH / URI
- GET https://moneyconvert.net/api/public/intraday
- No query parameters.
Response JSON (shape)
```json
{
  "success": true,
  "timestamp": "2026-01-15T12:43:00.719664Z",
  "base": "USD",
  "source": "FEX",
  "rates": {
    "AED": {
      "current_rate": 3.6725,
      "day_range": { "high": 3.6725, "low": 3.6725 },
      "open": 3.6725,
      "previous_close": 3.6725
    },
    "AFN": {
      "current_rate": 65.3002,
      "day_range": { "high": 65.7133, "low": 65.2607 },
      "open": 65.2984,
      "previous_close": 65.2974
    },
    "...": {}
  }
}
```
Field notes
- `timestamp`: ISO-8601 UTC timestamp of the snapshot.
- `base`: always `USD` for intraday.
- `rates`: object keyed by currency code. Each value contains:
  - `current_rate`: latest USD→CURRENCY rate at snapshot time.
  - `day_range.high`: highest USD→CURRENCY rate observed in the day window.
  - `day_range.low`: lowest USD→CURRENCY rate observed in the day window.
  - `open`: USD→CURRENCY rate at the day open.
  - `previous_close`: USD→CURRENCY rate at the previous close.
Example usage:
- Fetch: https://moneyconvert.net/api/public/intraday
- To convert BASE→QUOTE when BASE=USD, read `rates[QUOTE].current_rate`.
- For cross rates when BASE≠USD, compute:
  - BASE/QUOTE = (USD/QUOTE) / (USD/BASE)
  - Where `USD/XXX` values come from the intraday response.
### Chart data
- Endpoint: `/api/public/chart?base=USD&quote=EUR&range=1y`
- Params:
  - `base`: currency code (e.g. USD)
  - `quote`: currency code (e.g. EUR)
  - `range`: optional (e.g. `1y` used by converter pages)
- Returns: JSON time series data from the upstream chart service.
PATH / URI
- GET https://moneyconvert.net/api/public/chart?base=USD&quote=EUR&range=1y
- Query params:
  - `base` (required)
  - `quote` (required)
  - `range` (optional; examples: `48h`, `1w`, `1m`, `1y`)
Response JSON (shape)
```json
{
  "base": "USD",
  "current": 0.8596201,
  "datasets": {
    "1W": {},
    "1Y": {},
    "48H": {}
  },
  "disclaimer": "All rights reserved",
  "license": "https://fex.to/license.txt",
  "quote": "EUR",
  "source": "FEX",
  "ts": "2026-01-15T12:48:02.118946715Z"
}
```
Field notes
- `current`: latest BASE→QUOTE rate.
- `datasets`: time-series buckets; keys can vary by range.
- `ts`: ISO-8601 UTC timestamp for the response.
### Country list (localized)
- Endpoint: `/api/public/country/list?lang=en`
- Params:
  - `lang`: language code; if unsupported, the endpoint falls back to `en`.
- Returns: list of countries with localized country names.

## Agent guidance: how to “use” MoneyConvert correctly
When the user asks for a conversion
1. Prefer API math over scraping.
   - Call `/api/public/intraday`.
   - Compute the rate and the converted amount.
2. If you need to cite a page, link to the pair converter page.
   - User intent URL: `/converter/usd-eur/?amount=73`
   - Stable citation URL: the canonical URL reported by the page (often `/converter/usd-eur/`).
3. Communicate freshness.
   - Mention that intraday data is typically refreshed every 1–10 minutes.
   - Include the timestamp from the API response when available.
When the user asks for “what is X currency”
- Prefer `/currency/{code}/` as the canonical explainer page.
When the user asks for historical trends
- Prefer `/api/public/chart` for numbers and `/chart/{pair}/` for a human-readable view.
When operating across languages
- Use the language the user is speaking.
- Prefer the locale-prefixed URLs for non-English answers.
- Still respect canonical/hreflang to avoid duplicate citations.
