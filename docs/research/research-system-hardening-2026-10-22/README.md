# Ordered research system hardening

Implementation order: exact gate bindings; marginal-information follow-ups;
resumable stages; expanded evaluation; evidence provenance; canonical projections.
Luna/max remains the research default. The active ranked queue retains its prior
runtime until all phases pass integrated checks. Historical gates remain legacy.

1. **Verified:** research-gate/v2 pins full canonical statements and immutable
   source bodies. Every risky claim is selected, plus a deterministic ordinary
   sample. Exact IDs, hashes and Unicode spans reject substitution, duplication,
   stale inputs and fabricated quotes. Finish rechecks the current inputs.
   Validation: 68 focused tests passed; Ruff passed. Entailment remains a model
   judgment; exact binding alone does not establish factual truth.

2. **Verified:** standard follow-ups target unread scout discoveries, incomplete
   scout reports, unique fact floors and domain-specific primary-source/origin
   requirements. A cited blog alone no longer repeats research. Each concept
   records novel exact-normalized facts, mechanism-language counts and origin
   proxies. Supported novelty counts only gate-selected evidence and remains a
   lower bound. Validation: 71 focused tests and Ruff pass.

3. **Verified:** workers keep private briefs/events/errors and summaries for every
   attempt. Recognized transport/capacity/format failures retry at most twice
   within the original deadline. Gate response-format errors receive one fresh
   attempt; evidence mismatches and dissent stop. Exact worker inputs and output
   hashes permit reuse. Ranked research, render, gate, export and local website
   stages have separate content-bound checkpoints. Local publication never means
   remote deployment. Validation: 75 focused tests and Ruff pass, including
   transient recovery, output corruption and failed-stage resume.

4. **Verified:** the expanded harness supports /dr, CFE and rabbithole, fixed or
   live-assisted retrieval, three domains, exact full-statement blind judgments,
   quote matching, unique supported facts, mechanisms, contradictions and hierarchy.
   Completed six live-assisted /dr generation trials and six Astra/high blind
   judgments. All six used live search. See [comparison.md](comparison.md).
   The preserved prior baseline contains 36 frozen-evidence trials spanning all
   three skills, three models and two efforts, kept separate from this canary.
   Sol/medium yielded 56 accepted facts across 18 grounded concepts in 247 seconds;
   Luna/max yielded 17 across 8 in 421 seconds. Input tokens were 203,606 versus
   536,994; output tokens were 8,185 versus 46,580. Model and effort vary together.
   Reference facts await human review. Rejection includes missing pinned evidence,
   not only factual contradiction. USD is unknown; optional estimates require a
   dated sourced rate card and avoid double-counting cached tokens.
   Validation: 92 focused tests and Ruff pass. Raw evidence and execution logs are
   private; the public report contains aggregate measurements only.

5. **Verified:** Codex's library compatibility CLI preserves the existing FTS
   index and archives old/new source bodies around writes. Stable snapshot and
   exact-span evidence IDs bind text hashes. Version/ETag/modification metadata,
   original raw bytes where available, origin annotations and derivation links
   remain private. Cohort bundles retain shared sources plus each concept's
   own claim hashes, citations and gaps; siblings receive bounded relevant seeds.
   Backed up metadata and SQLite before archiving all 9,695 current sources.
   No body/hash mismatches occurred. Original raw bytes were available for 177;
   59 entries signal already-overwritten historical bodies that hashes cannot
   reconstruct. [Library audit](library-audit.json).
   Validation: 96 focused tests and Ruff pass, including version refresh, Unicode
   span identity, origin annotations and concept-specific bundle reuse.
