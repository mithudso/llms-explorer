# OV — Out-of-sample validation

Question this family answers: Was the number measured on data the choice never saw?

25 passes. Each row is one pass: one evaluation method, one check, one fix. `Fails →` is the severity the finding carries when the check fails (see SKILL.md § Severity). Sources for every method are in `../evaluation-methods.md`.
