Use `ui-deep-optimizer` to review an existing interface across its workflows, visual hierarchy, accessibility and responsive states. It selects applicable methods from a 70-method catalogue, records evidence and applies verified Medium-or-higher fixes to editable targets. A clean result requires a complete no-edit sweep and current verification for the stated scope.

Source without a runnable renderer has limited evidence. Screenshots, specifications and external sites without edit authority receive findings rather than edits. User research methods require authorized evidence; the skill does not pretend a simulated evaluation is a participant study.

**Use it for:** "audit this dashboard", "improve this interface across mobile and desktop", or "review these workflows and accessibility together".

**Not for:** a new interface or visual-only brand work; use the appropriate design skill instead.
