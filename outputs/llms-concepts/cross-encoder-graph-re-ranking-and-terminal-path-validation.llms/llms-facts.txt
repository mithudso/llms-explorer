# Cross-Encoder Graph Re-Ranking and Terminal Path Validation — Facts
- Cross-encoder re-ranking models (e.g. BGE-Reranker, Cohere Rerank) applied to serialized multi-hop graph candidate paths improve NDCG@10 by 12–18% over bi-encoder similarity rankings by capturing full inter-token cross-attention. — https://arxiv.org/abs/2309.07597
- Terminal path validation filters spurious graph paths that share surface entities but lack causal or deductive connection to the user prompt, reducing downstream LLM hallucination rates by > 30%. — https://arxiv.org/abs/2310.03267
- Applying cross-encoders as a stage-2 reranker over top-50 graph candidate subgraphs balances inference latency (15–30ms per query on GPU/Apple Silicon) with maximum precision gains. — https://arxiv.org/abs/2309.07597
