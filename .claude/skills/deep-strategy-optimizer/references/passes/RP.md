# RP — Reproducibility, provenance and claim verification

Question this family answers: Does every claim trace to a run that reproduces?

40 passes. Each row is one pass: one evaluation method, one check, one fix. `Fails →` is the severity the finding carries when the check fails (see SKILL.md § Severity). Sources for every method are in `../evaluation-methods.md`.
