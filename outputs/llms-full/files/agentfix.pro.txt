## FAQ

### Will this hurt my Google SEO?

No. All files added (llms.txt, schema.org, .well-known) are AI / agent-readiness signals that complement classic SEO. Search rankings are not affected.

### Do I really not need a developer?

Correct. The install guide for your CMS is screenshot-by-screenshot. Most buyers finish in 5-10 minutes using only their CMS dashboard (no code editor, no terminal). For platforms with limits on root files (Webflow, Tilda, Shopify), we include a Cloudflare Worker template.

### How is this different from agentready.tools?

agentready.tools delivers fixes as a GitHub Pull Request, which assumes you have a Git repo and know how to merge a PR. AgentFix delivers a ZIP with platform-specific install guides for WordPress, Webflow, Tilda, Shopify, and cPanel - the platforms non-developers actually use.

### What if my site is on Wix or Squarespace?

Wix and Squarespace have limited control over root files. The pack still includes schema snippets you can paste into the `<head>`. For the .well-known files, a Cloudflare Worker is required (instructions included).

### Money-back guarantee?

Yes, with one limit. Refunds are available within 14 days only if the pack failed to build or is technically broken. Once any file from the pack has been downloaded or installed on your site, the purchase is non-refundable. We watermark each ZIP with the buyer email in the README to discourage redistribution.

### Do you offer a certificate?

Yes. After installing the pack, re-scan your site at agentfix.pro. If your score reaches 80% or higher, an Agent-Ready certificate is issued automatically with a public verification page, embeddable badge image, and full-size diploma SVG.

# Commerce and Payments layer

AgentFix publishes a two-file discovery layer for AI shopping agents. This is the same pattern we recommend to customers of the Pack ($29+) tier.

## Pay-ready docs

Human and agent-readable pricing, checkout flow, provider fingerprints and test-mode instructions.

- URL: https://agentfix.pro/llms-pay.md
- Content-Type: text/markdown

## Checkout schema

Declarative product catalog + checkout flow (v0.1 draft, community-comment).

- URL: https://agentfix.pro/.well-known/agent-checkout.json
- Content-Type: application/json
- Fields: version, products[], checkout_flow, providers[], test_mode

## Signup schema

Guest-first signup model, no account needed for scan or buy. Post-purchase Pro entitlement via email + license_key + Chrome extension activation endpoint.

- URL: https://agentfix.pro/.well-known/agent-signup.json
- Content-Type: application/json
- Fields: version, signup_required (false), signup_model ("guest_first"), post_purchase_activation, identity_privacy

## Commerce checks in scanner

The AgentFix scanner covers 9 commerce/payments signals (Category: Commerce): checkout_form_semantics, checkout_autocomplete_cc, checkout_provider_detected, checkout_flow_json, llms_pay_md_present, llms_txt_references_pay, signup_autocomplete_hints, signup_sso_present, signup_flow_json. Sites without commerce intent (no /checkout, /pricing, /plans, /signup routes) skip the category.

See https://agentfix.pro/methodology for the full 52-signal checklist across 9 categories: Content for agents, Commerce, Agent web standards, Browser UX, Discoverability, Structured data, AI policy, Agent protocols, and AI visibility.
