## How it works

- [statement] When replacing the old Flex resource configuration, remove its obsolete state binding with terraform state rm mongodbatlas_flex_cluster.this. MongoDB warns that skipping this step plans deletion of the existing cluster; HashiCorp documents that state rm removes the binding without destroying the remote object. If the old configuration remains, Terraform can instead plan to create a replacement for the forgotten resource. - [statement] For a converted deployment whose state is managed by Spacelift, its documented Tasks workflow can run terraform import on the owning stack. This is an application of Spacelift's generic import mechanism to MongoDB's post-conversion import procedure.
