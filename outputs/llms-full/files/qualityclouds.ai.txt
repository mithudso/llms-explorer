# Quality Clouds Documentation

> Technical documentation for Quality Clouds, the independent governance layer for human and AI-generated code. Covers the Platforms products (ServiceNow, Salesforce, Microsoft Dynamics 365) and Norma, the repository-based product for Git and AI-native development. Includes onboarding, connecting instances and repositories, scans, rules and rulesets, Quality Gates, MCP and IDE integrations, reporting, and administration for developers, architects, and platform owners.

Quality Clouds works through two connection models.

The Platforms products connect to ServiceNow, Salesforce, and Dynamics 365 through official REST APIs using read-only access. They analyse platform metadata and configuration elements, never transactional or business data.

Norma connects to GitHub and Bitbucket repositories and scans the code held there. It is repository-based and technology-agnostic. It does not govern platform metadata or configuration.

Both apply the Quality Clouds rule catalogue plus customer-defined rules, and both enforce policy through Quality Gates in CI/CD pipelines and through MCP inside AI coding tools and IDEs.

For commercial information, product pages, and pricing, see [qualityclouds.ai](https://qualityclouds.ai). For its `llms.txt`, see [qualityclouds.ai/llms.txt](https://qualityclouds.ai/llms.txt).

## About Quality Clouds

Quality Clouds is an enterprise SaaS company founded in 2015. It provides AI code governance through two product lines: the Platforms products for ServiceNow, Salesforce, and Microsoft Dynamics 365, including the AI agents built on those platforms such as Salesforce Agentforce and ServiceNow Now Assist; and Norma, which governs Git repositories and the code produced in AI-native development tools including Cursor, Claude Code, GitHub Copilot, VS Code, Replit, and Lovable.

The rule catalogue and scan history cover 950+ governed enterprise platform instances and more than 13 million catalogued issues over 9 years. ISO 27001:2022 certified. Headquarters in London, with offices in Barcelona and New York.
