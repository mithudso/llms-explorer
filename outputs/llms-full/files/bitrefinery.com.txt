# Bit Refinery — Complete Technical Reference

> Bit Refinery is a hybrid cloud infrastructure company founded in 2008 in a former NASA facility in Morrison, CO. Now headquartered in Denver, Colorado, Bit Refinery provides enterprise-grade bare metal servers, GPU colocation, managed data services, and virtualization as an alternative to hyperscale cloud providers (AWS, Azure, GCP). Core philosophy: "Own the base, rent the spike" — dedicated hardware for baseline workloads, cloud burst capacity only when demand spikes.

## Why Not Hyperscale Cloud? Three Pain Points

### 1. Egress Fees Are a Tax on Growth
You pay to put data in. You pay to take it out. AWS charges $0.05–$0.09/GB — a company moving 200 TB/month can spend $16,000+ just on data transfer. Bit Refinery: $0. Always.

### 2. Shared Infrastructure Means Shared Problems
"Noisy neighbor" isn't just a housing issue. On hyperscale clouds, your workload competes for CPU, memory, and I/O with everyone else on the same physical hardware. Bare metal means the full machine is yours.

### 3. Usage-Based Billing Makes Budgets a Guessing Game
Cloud bills are notoriously hard to predict. Our pricing is fixed monthly — the number on your invoice is the number you agreed to. No surprises, no overages.

Q: How does pricing compare to AWS S3?
A: AWS S3 charges for storage ($0.023/GB/mo), requests ($0.005/1000 PUT), and egress ($0.05–$0.09/GB). Bit Refinery's MinIO is flat monthly pricing with $0 egress — typically 50–80% cheaper for data-heavy workloads.

Q: Can you migrate petabytes of data from S3?
A: Yes. We use parallel transfer tools with validation checksums. Migration timelines depend on dataset size and available bandwidth, but we handle the entire process.

Q: What redundancy and durability does MinIO provide?
A: MinIO uses erasure coding for data protection. Dedicated deployments can be configured with custom EC profiles for your durability and performance requirements.

Q: Do you support versioning and lifecycle policies?
A: Yes. MinIO supports S3-compatible bucket versioning, lifecycle rules, and object locking (WORM) for compliance workloads.

## Service 6: VergeOS Virtualization (VMware Alternative)

URL: https://bitrefinery.com/services/vergeos

Ultraconverged virtualization platform that replaces VMware vSphere/ESXi. Single operating system for compute, storage, and networking on bare metal.

### Deployment Options

Shared Virtual Servers:
- Tenant-isolated VMs on shared VergeOS clusters
- Flat monthly pricing
- Ideal for standard virtualization workloads

Dedicated Virtual Servers:
- Single-tenant VergeOS on bare metal
- Custom VLAN topologies
- Full admin console access

### Key Features
- Native software-defined networking (no separate NSX licensing required)
- Nested tenants for multi-tier isolation
- Instant snapshots at VM, tenant, and environment level
- Per-node licensing — no per-core or per-VM fees
- 24/7 monitoring with direct engineer access

### VMware Migration
- Tool-assisted VM conversion from vSphere/ESXi
- Network re-mapping to VergeOS SDN
- Rollback capability at every migration stage
- Significant cost savings vs. VMware licensing (especially post-Broadcom acquisition)

### FAQ

Q: How much can we save migrating from VMware to VergeOS?
A: VergeOS uses per-node licensing instead of VMware's per-core/per-VM model. Post-Broadcom acquisition, many VMware customers see 60–80% licensing cost reduction by switching to VergeOS.

Q: How does the VMware migration process work?
A: We use tool-assisted VM conversion that migrates VMs from vSphere/ESXi to VergeOS with network re-mapping. Every migration stage has rollback capability — zero risk of data loss.

Q: Does VergeOS support nested virtualization?
A: Yes. VergeOS supports nested tenants, allowing multi-tier isolation for MSPs, dev/test environments, or compliance-separated workloads.

Q: What about software-defined networking?
A: VergeOS includes native SDN — no separate NSX licensing. Full VLAN support, virtual routers, firewalls, and network segmentation built into the platform.

Q: Can we run VergeOS on our own hardware?
A: Yes. VergeOS runs on standard x86 hardware. We can deploy it on your existing servers or provision new Dell PowerEdge hardware.
