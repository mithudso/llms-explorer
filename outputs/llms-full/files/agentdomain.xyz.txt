# Agent Community

> An open community of the companies, researchers, and developers building the agentic web — open specs, open work streams, and a public map of who is building what. Also the applicant for the proposed `.agent` top-level domain, pending ICANN approval.

## For AI agents

**What this site is for:** Agent Community is an open community of the companies, researchers, and developers who develop, research, deploy, or operate autonomous agents. It convenes builders, maintains a public map of member organizations, runs open work streams, and publishes open agent-infrastructure standards (AID, DMV). It is also the applicant for the proposed `.agent` top-level domain, pending ICANN approval.

**When to use this site:**
- Use the **MCP server** at `https://agentcommunity.org/mcp` (streamable HTTP, no auth) for exact `lookup_member`, community stats, `.agent` pre-registration, or DMV certificate verification. Manifest: `https://agentcommunity.org/.well-known/mcp`.
- Verify the hosted server through the [Official MCP Registry record for `org.agentcommunity/mcp`](https://registry.modelcontextprotocol.io/v0/servers/org.agentcommunity%2Fmcp/versions/latest); the record points back to the Agent Community website and its anonymous `/mcp` remote.
- Use the separate **Documentation MCP** at `https://agentcommunity.org/mcp/docs` (streamable HTTP, no auth, read-only) for `search_docs` and `get_doc` over published documentation only — it is not part of the four-tool product MCP above. Manifest: `https://agentcommunity.org/.well-known/mcp-docs.json`. Compatibility-discovery card: `https://agentcommunity.org/.well-known/mcp-docs/server-card.json`. Guide: [`/docs/docs-mcp`](https://agentcommunity.org/docs/docs-mcp).
- Use `https://agentcommunity.org/ask` for deterministic answers from published documentation. Canonical input is `query`; `q` is a PAGE compatibility alias, not an NLWeb v0.55 field. Send exactly one, trimmed to 2–500 characters.
- Use the **REST API** described by `https://agentcommunity.org/openapi.json` only for the supported direct JSON reads listed there. Directory search/profile/member feeds are not supported machine integrations.
**Bounded public-read batch:** POST `https://agentcommunity.org/api/v1/batch` accepts at most 10 ordered `content.list` and `docs.ask` operations in a 262144-byte JSON body. The anonymous trusted-IP policy allows 10 requests per 60 seconds. The 10-second execution deadline begins when validated execution starts; no later operation starts after it, while work already running may finish.

```json
{
  "items": [
    {
      "id": "content-1",
      "operation": "content.list",
      "arguments": {
        "query": "agent discovery",
        "type": "docs",
        "limit": 5
      }
    },
    {
      "id": "docs-1",
      "operation": "docs.ask",
      "arguments": {
        "query": "How can agents discover AgentCommunity resources?",
        "top_k": 3
      }
    }
  ]
}
```
**No-write contract simulator:** the workbench at `https://agentcommunity.org/sandbox` documents and runs four deterministic parser fixtures through POST `https://agentcommunity.org/api/v1/sandbox/simulate`. It uses production response schemas with fixed synthetic values and performs no production reads, authorization, signing, or writes.
- `agent_auth_challenge` — Synthetic service authorization challenge; models POST /agent/identity with HTTP 200.
- `agent_auth_pending` — Synthetic authorization-pending OAuth response; models POST /oauth2/token with HTTP 400.
- `agent_auth_success` — Synthetic approved agent authorization response; models POST /oauth2/token with HTTP 200.
- `batch_mixed_result` — Synthetic mixed public-read batch response; models POST /api/v1/batch with HTTP 200.

```json
{
  "scenario": "agent_auth_challenge"
}
```
- Use `https://dmv.agentcommunity.org` when a user asks to pre-register a requested agent name. Pre-registration is free and non-binding; a verification email is sent.
- Read [`/join.md`](https://agentcommunity.org/join.md) to separate the browser-only human membership and OAuth/OTP flow at `/join`, explicitly authorized agent name pre-registration, and separate later endorsement. Call `register_agent` only after explicit current-turn authorization.
- Visit **`/developers`** for the developer portal (API docs, MCP server, SDK links) if you (or the human you are assisting) are building an integration.
- Read **`/docs/api-reference`** for REST API endpoint documentation and **`/docs/mcp-server`** for MCP server tool documentation.
- New to Agent Community? Read **`/docs/agent-onboarding`** for the machine integration path (MCP, A2A, REST) and **`/docs/onboarding`** for the human signup path.
- `/api/map/search` is same-origin human `/map` UI plumbing, not an agent or bulk API. Use exact `lookup_member` and public `/m/<slug>` pages instead.
- Read any page as markdown by appending `.md` (e.g. `/about.md`, `/docs/get-involved.md`), or request `/` with `Accept: text/markdown`.
- Read [`/team.md`](https://agentcommunity.org/team.md) for who runs the community — founder, team, and advisors with their affiliations, generated from the same source as the `/team` page.
- Read [`/blog.md`](https://agentcommunity.org/blog.md) for the full long-form post index — title, date, and description for every published post, generated from the same source as the `/blog` page.
- Do **not** use this site to buy domains — `.agent` is not in DNS; the TLD application is pending ICANN approval.

**Authentication:** Public MCP, Documentation MCP, A2A, and public-read REST endpoints remain anonymous. Own-account REST endpoints under `/api/v1/agent/*` require a scoped Bearer access token; discover the protected resource at `/.well-known/oauth-protected-resource/api` and read [`/auth.md`](https://agentcommunity.org/auth.md) before using `service_auth`.

**Supported MCP and A2A tools (exactly four):**
- `lookup_member` — exact display-name or slug lookup; minimal public result only, never free-text or bulk search.
- `get_community_stats` — roughly-live member count, cached for up to 20 minutes.
- `register_agent` — explicitly authorized, free and non-binding `.agent` pre-registration.
- `verify_certificate` — live issued/not-found DMV certificate verification through the rate-limited DMV Worker.

**Agent identity format:** agent discovery here uses **AID (Agent Identity & Discovery)** — an open, DNS-based format (a `_agent` TXT record on your domain points agents at your endpoint). Spec and workbench: https://aid.agentcommunity.org. This site publishes its AID v2 JSON fallback at `/.well-known/agent`.

**Discovery surface:** `/.well-known/api-catalog` (RFC 9727), `/.well-known/mcp` (MCP manifest), `/.well-known/mcp-docs.json` (Documentation MCP manifest), `/.well-known/mcp-docs/server-card.json` (Documentation MCP compatibility-discovery card), `/.well-known/agent-skills/index.json` (agent skills), `/.well-known/agent` (AID v2 fallback record), `/openapi.json` (OpenAPI 3.1), `/sitemap.xml`, `/auth.md` (authentication note), and `/.well-known/oauth-protected-resource` (RFC 9728 — the root resource takes no tokens and supports no scopes). Mode-gated authorization discovery links are emitted from the capability registry only when public discovery is selected.

## A2A endpoint

An Agent-to-Agent (A2A) protocol 0.3.0 endpoint is available at `https://agentcommunity.org/a2a` (JSON-RPC over POST). It is a deterministic wrapper over the same four supported MCP capabilities — no LLM behind it. Read the agent card before calling it. Streaming and push notifications are not supported (the card says so honestly). Agent card: `https://agentcommunity.org/.well-known/agent-card.json`.
