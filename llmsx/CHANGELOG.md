# Changelog

All notable changes to this project are documented in this file. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.2.9] — 2026-11-07

### Fixed

- Generated wheel metadata now separates direct Git dependency URLs from their
  environment markers with whitespace, as PEP508 requires. Strict pip parsers
  accept the optional corpus/dev dependencies; base and TUI installs do not
  fetch the private renderer.
- Website and guide install commands use the pip-compatible `llmsx[tui] @ URL`
  direct reference instead of appending extras to the wheel URL.

### Added

- Public `.llms` context packs and `llmsx context list/get`, with transfer
  integrity checks and refusal to overwrite an existing output directory.
- The private corpus renderer is optional. Public browsing/context/TUI paths
  install without repository credentials; advanced corpus rendering retains
  its explicit authorized-access requirement.

## [Unreleased]

### Changed

- `llmsx.family` renders `llms.txt` and `llms-full.txt` through the shared `llms-txt`
  library (`llms_txt.family.render_index` / `render_full`) through the optional
  `corpus` integration. Public API (`build_family`, `render_*`, `Family`, `FULL_GRAMMAR`) is
  unchanged and every file is byte-identical except the `llms.txt` provenance
  comment, which now reads `generated by llms-txt 0.1.0 · N entries · DATE`.
  `llms-small.txt`, `llms-facts.txt` and `llms-vocabulary.txt` stay in llmsx: they
  are corpus-aware (token budget, per-topic anchors, coverage gaps).

## [0.2.6] — 2026-10-18

### Added

- `llmsx explorer` queue viewer (`u`): a research monitor listing every run that
  holds concepts on the research machine (`/dr` runs, explorer frontier batches,
  research suite runs, website runs), how many of each run's concepts are done
  and which are checked out, plus the queue's size. It reads the public
  `GET /api/research/queue` endpoint (also shown at https://llms-explorer.com/queue/),
  refreshes every 30 s and on `R`; `LLMSX_API_URL` points it elsewhere.

## [0.2.5] — 2026-10-13

### Added

- `llmsx explorer`: a concept opens on its facts (the pack, else the hub's
  `llms-facts.txt`).
- llms-family tabs render as keyword-highlighted lines with a cursor
  (`llmsx.explorer_lines`).
- Scratchpad: `y` / 📌 Save line appends a line with its source to
  `$LLMSX_HOME/scratchpad.md`; `p` / 📝 Scratchpad edits and copies it.
- `U` marks every concept with no facts file `further-research` and queues it.
- `↓` / `↑` move focus to the widget below / above outside lists and dropdowns.
- The complete user guide ships in the package (`llmsx/USER_GUIDE.md`): `g` in
  the app, `llmsx explorer --guide`, and https://llms-explorer.com/explorer/guide/.

## [0.1.0] — 2026-09-02

Initial release.

### Added

- `llmsx tree {show,detail,search,frontier}` — read-only browser over the
  generated llms-explorer concept tree (`site/src/data/tree.json`), zero
  third-party dependencies.
- `llmsx tui` — Textual browser over the same tree (`pip install 'llmsx[tui]'`).
- `llmsx concepts {list,show,serve}` — catalog and read llms-concept-abstractor
  concept packs (`<slug>.llms/` directories), zero third-party dependencies.
- `llmsx concepts tui` — Textual browser/editor over concept packs, ported
  from the hub-manager Concepts tab (`pip install 'llmsx[tui]'`).
- `llmsx family <topic>` / `llmsx optimize <file-or-text>` — one-turn CLI
  wrappers over `llmsx.skills.run_skill` for `concept-family-explorer` and
  `llms-deep-optimizer` (`pip install 'llmsx[skills]'`).
- `llmsx.skills` — load and run a `SKILL.md` against a model, with an
  injectable client for offline testing.
