# OneNotify full AI context

OneNotify, called 一条通知 in Chinese, is an Android notification management and automation product. The public website is https://onenotify.app/ and the documentation site is https://docs.onenotify.app/.

## Product summary

OneNotify helps people convert scattered Android notifications into executable rules. A user can match notifications from specific apps, keywords, regular expressions, time windows, priority levels, scenes, and phone context. Matched notifications can then be filtered, forwarded, read aloud, pushed to wearables, or used to trigger other actions.

The core promise is: filter distractions, keep important information, and send notifications exactly where they are needed.

## Core capabilities

### Rule matching

OneNotify can match notifications by source app, keyword, regular expression, time, priority, and related notification fields. This makes it suitable for high-signal rules such as keeping meeting alerts, suppressing shopping promotions, or forwarding transaction notices.

### Scene awareness

OneNotify supports context-aware scenes. Examples include working hours, meetings, home mode, commuting, Wi-Fi state, charging state, Bluetooth wearable connection, and other phone context. Scene rules help users avoid global all-or-nothing notification behavior.

### Multi-channel forwarding

OneNotify can send matched notification information to Webhook, email, SMS, wearables, and voice output. It is useful when a notification should leave the phone and arrive in another tool, device, or workflow.

### Notification analytics

OneNotify includes notification statistics and trend views. These help users understand which apps generate the most notifications, how many notifications were filtered, and how many forwarding actions succeeded.

### Privacy model

Rule matching and most automation happen locally on the Android device. Notification content is not uploaded to a OneNotify server for matching. Content leaves the device only when the user actively configures actions such as Webhook, email, SMS, or another forwarding destination.

## Common use cases

- Filter low-value promotional notifications while keeping payment, travel, meeting, and security alerts.
- Forward important Android notifications to Webhook endpoints for personal automation.
- Send selected alerts to email or SMS when the phone is not the primary work surface.
- Push important notifications to a wearable during commuting or exercise.
- Read meeting or high-priority messages aloud during work hours.
- Silence low-value notifications at home while keeping urgent alerts.

## FAQ

### What problem does OneNotify solve?

It turns scattered Android notifications into configurable rules: filter low-value noise, keep important alerts, and run forwarding, read-aloud, vibration, or other actions by condition.

### Which system permissions are required?

The core workflow needs Android notification access. SMS, phone, location, Bluetooth, and accessibility permissions are requested only when the user enables features that depend on them.

### Will notification content be uploaded to a server?

Rule matching and most automation run locally on the device. Content is sent out only when the user actively configures forwarding actions such as Webhook, email, or SMS.

### Where can users download OneNotify?

Users can download the Android package from https://onenotify.app/api/download-apk/ or install it from Google Play at https://play.google.com/store/apps/details?id=cn.skyrin.ntfh.

## Product category and comparison

Category: Android utility, notification manager, notification automation, personal automation.

OneNotify is different from a simple notification blocker because it can route matched notifications into actions. It is different from a general workflow automation tool because notification matching is the primary trigger and Android notification privacy is central to the design.
