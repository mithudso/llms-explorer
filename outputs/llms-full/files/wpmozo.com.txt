# License activation

To ensure uninterrupted plugin updates, it is essential to add your license key. Follow the steps below to locate and apply your license key in the plugin’s backend settings:

1. Log in to your [wpmozo.com account](https://wpmozo.com/my-account/downloads/) and navigate to the account area.
2. Locate the license key provided for plugin update.
3. **Copy the license key** to your clipboard.
4. Access your **WordPress admin** area (wp-admin).
5. From the dashboard, go to “ **WPMozo Checkout Manager**”.
6. **Paste the license key** into the appropriate field.
7. Click on the “ **Activate**”.

By following these steps, you will successfully add your license key and activate the plugin, enabling you to receive seamless updates for your WPMozo product.

# Installation

### From WordPress Dashboard

Go to **WordPress Dashboard** >> **Plugins** >> **Add New** >> **Upload Plugin** >> **Choose File** >\> Browse **wpmozo-checkout-manager-for-woocommerce.zip** and click **Install Now** >> **Activate Plugin**

![](https://wpmozo.com/wp-content/uploads/2023/09/installation-of-wpmozo-product-carousel-for-woocommerce.webp)

1. Go to Plugins.
2. Select Add New Option.
3. Click on button named Upload Plugin.
4. Browse for file **wpmozo-checkout-manager-for-woocommerce.zip**
5. Install the plugin.
6. Click on **Activate Plugin** to activate.

![](https://wpmozo.com/wp-content/uploads/2023/09/activate-the-plugin-check-manager-for-woocommerce.webp)

### Manually uploading via FTP

- Extract **wpmozo-checkout-manager-for-woocommerce.zip**
- Connect to your server using an FTP application.
- Navigate to **wp-content/plugins/**.
- Upload the **wpmozo-checkout-manager-for-woocommerce** directory in the plugins directory of your server.
- Go to **WordPress Dashboard** >> **All Plugins** \> > **Activate WPMozo Checkout Manager For WooCommerce**.

# How to Disable File Editing in the WordPress Dashboard?

## **Why Disable File Editing in WordPress?**

WordPress comes with a built-in file editor that allows users to edit theme and plugin files directly from the dashboard. While this feature can be convenient, it also poses a security risk. If a hacker gains access to your WordPress admin panel, they could easily inject malicious code into your files.

## **How to Disable File Editing in WordPress?**

To prevent unauthorized access and reduce security risks, you can disable the file editing feature in WordPress by adding a simple line of code to your `wp-config.php` file. Here’s how to do it:

1. **Access Your WordPress Files:**

- Use an FTP client or your web hosting file manager to access the WordPress installation files.

1. **Open the `wp-config.php` File:**

- Navigate to the root directory of your WordPress installation and locate the `wp-config.php` file.

1. **Add the Following Code:**

```
   define('DISALLOW_FILE_EDIT', true);
```

- Insert this line of code anywhere above the line that says `/* That's all, stop editing! Happy blogging. */`.

1. **Save the File:**

- Save your changes and re-upload the `wp-config.php` file to your server if using an FTP client.

## **What Does This Code Do?**

This snippet disables the theme and plugin editor from the WordPress admin dashboard, effectively preventing any file editing via the dashboard interface. This helps protect your website from unauthorized file modifications, making it harder for hackers to exploit your site.

# How to use

Once you enable the “WPMozo Mini Cart for WooCommerce” plugin, it adds an option “WPMozo Mini Cart” to your WordPress Dashboard. You can now access the Mini Cart settings panel from here.

![](https://wpmozo.com/wp-content/uploads/2024/03/wpmozo-mini-cart-panel.webp)

In the Mini Cart panel, the first setting is to enable the Mini Cart.

![](https://wpmozo.com/wp-content/uploads/2024/03/enabled-mini-cart-on-your-site.webp)

Once you enable the option, you will have the ability to add the mini cart to the menu. Below, we have provided instructions on how to add the mini cart in both the Classic theme and the Block theme.

### Adding WPMozo Mini Cart to Menu in Site Editor (Block Theme)

1. **Login to WordPress:**
   - Log in to your WordPress Dashboard.
2. **Navigate to the Site Editor:**
   - In the WordPress admin menu, go to “Appearance” and select “Site Editor.”
3. **Select the Navigation Block:**
   - Once in the Site Editor, edit the Navigation.
4. **Add a Block for Mini Cart:**
   - Search for the block WPMozo MIni Cart.

![](https://wpmozo.com/wp-content/uploads/2024/03/add-wpmozo-in-block-theme.webp)![](https://wpmozo.com/wp-content/uploads/2024/03/output-of-site-editor-theme.webp)

### Adding WPMozo Mini Cart to Menu in Classic Theme

1. **Login to WordPress:**
   - Log in to your WordPress Dashboard.
2. **Navigate to Menus:**
   - In the WordPress admin menu, go to “Appearance” and select “Menus.”
3. **Create or Edit a Menu:**
   - If you already have a menu, select it from the drop-down. If not, you can create a new menu by clicking “Create a new menu.”
4. **Add WPMozo Mini Cart to the Menu:**
   - Drag or click on the Add to Menu button to add the WPMozo Mini Cart to the menu.

![](https://wpmozo.com/wp-content/uploads/2024/03/add-menu-to-theme-header1-2.webp)![](https://wpmozo.com/wp-content/uploads/2024/03/default-header.webp)

### Customization

When you enable the settings, you will have various customization options for the mini cart:

1. **Display Type:** You can choose from options like dropdown, overlay, off-canvas, and modal display.
2. **Icon:** There are 7 options available for selecting the mini cart icon.
3. **Total Quantity Badge:** Toggle to show the total quantity badge.
4. **Subtotal After Icon:** Toggle to display the subtotal after the icon.
5. **Display Heading:** You can choose to display the heading and product information.

![display-type-and-icon-setting](https://wpmozo.com/wp-content/uploads/2024/03/display-type-and-icon-setting.webp)![](https://wpmozo.com/wp-content/uploads/2024/03/action-of-mini-cart-.webp)

# License activation

To ensure uninterrupted plugin updates, it is essential to add your license key. Follow the steps below to locate and apply your license key in the plugin’s backend settings:

1. Log in to your [wpmozo.com](https://wpmozo.com/my-account/downloads/) account and navigate to the account area.
2. Locate the license key provided for plugin update.
3. **Copy the license key** to your clipboard.
4. Access your **WordPress admin area** (wp-admin).
5. From the dashboard, go to “ **WPMozo Mini Cart**” and select “ **License**.”
6. In the license settings section **paste the license key**.
7. Click on the “ **Activate**“.

# How to use

## Add widget on page

The **WPMozo Product Grid for WooCommerce** is a free plugin that allows you to showcase your products within an engaging grid layout.

To showcase the product grid on your site, go to your WP admin panel >> Page >> create or edit a page.

Now, on the left side, under **WPMozo**, you’ll find the **WPMozo Product Grid** widget.

![](https://wpmozo.com/wp-content/uploads/2025/01/product-grid-add-on-page.webp)

To add the widget simply drag and drop it onto the desired section of the page.

![](https://wpmozo.com/wp-content/uploads/2025/01/general-setting-of-wpmozo-product-grid-1024x651.webp)

### General Setting

The **General Settings** panel allows you to control the structure and spacing of your product grid layout.

**Columns**

- Set the number of product columns in the grid.

**Column Spacing**

- Adjust the horizontal spacing between columns (in %).

**Row Spacing**

- Adjust the vertical spacing between rows (in EM).

### Query Settings

![](https://wpmozo.com/wp-content/uploads/2025/01/product-grid-query-setting-1024x670.webp)

- **Product View Type**
  - Choose the type of products to display: Default, Featured, Sale, Best Selling, or Top Rated.
- **Number of Products**
  - Set the total number of products to display. Use `-1` to display all products.
- **Order By**
  - Determine the sorting criteria for products: Date, Modified Date, Menu Order, Title, Slug, ID, Random, Stock Status, Price, or None.
- **Order**
  - Choose the sorting order: Descending or Ascending.
- **Include Categories**
  - Specify categories to include in the grid (separate values with commas or Enter key).
- **Include Tags**
  - Specify tags to include in the grid (separate values with commas or Enter key).
- **Taxonomies Relation**
  - Set the relation for taxonomies: `AND` (all conditions must match) or `OR` (any condition can match).
- **Hide Out of Stock Products**
  - Option to hide products that are out of stock from the grid.

### Display Options

![](https://wpmozo.com/wp-content/uploads/2025/01/display-settings-for-wpmozo-product-grid-.webp)

- **Layout**
  - Choose a layout style: Default, Layout 1, or Layout 2.
- **Pagination Type**
  - Select the pagination method: Pagination or Load More.
- **Pagination Alignment**
  - Align pagination: Left, Center, or Right.
- **Pagination Previous/Next Text**
  - Customize the text for previous and next buttons using the `|` separator.
- **Ajax Pagination**
  - Enable or disable Ajax-based pagination.
- **Equal Height**
  - Toggle to ensure equal height for all product cards.
- **Masonry**
  - Toggle to enable a masonry-style layout.
- **Display Out of Stock Label**
  - Toggle to show a label for out-of-stock products.
- **Enable Quick View**
  - Toggle to allow users to view product details quickly.
- **Show Title**
  - Toggle to display the product title.
- **Show Featured Image**
  - Toggle to display the product’s featured image.
- **Featured Image Size**
  - Choose the size for the featured image (e.g., WooCommerce Thumbnail).
- **Show Rating**
  - Toggle to display product ratings.
- **Show Price**
  - Toggle to display product prices.
- **Show Add to Cart Button**
  - Toggle to display the “Add to Cart” button.
- **Show Sale Badge**
  - Toggle to display a sale badge on discounted products.
- **Sale Badge Type**
  - Choose the style of the sale badge: Sale Label or Sale Percentage.

### Responsive Feature

![](https://wpmozo.com/wp-content/uploads/2025/01/responsive-setting-for-product-grid.webp)

#### **Mobile Settings**

- **Columns**
  - Set the number of product columns displayed on mobile devices (default: 1).
- **Column Spacing**
  - Adjust the horizontal spacing between columns (in PX) for mobile (default: 20px).
- **Row Spacing**
  - Adjust the vertical spacing between rows (in PX) for mobile (default: 20px).

#### **Tablet Settings**

- **Columns**
  - Set the number of product columns displayed on tablets (default: 2).
- **Column Spacing**
  - Adjust the horizontal spacing between columns (in PX) for tablets (default: 30px).
- **Row Spacing**
  - Adjust the vertical spacing between rows (in PX) for tablets (default: 30px).

## Customization Options

# How to use

Once you activate the **Tab Manager for WooCommerce** plugin, it adds two settings named ‘ **WPMozo Tab Manager**‘ and ‘ **Products Tabs**‘ to your website.

![](https://wpmozo.com/wp-content/uploads/2024/02/wpmozo-tab-manager-setting-page-1.webp)

## **Manage Default Tabs**

#### **WPMozo Tab Manager**

Here, you can modify the default text of WooCommerce tabs or show/hide existing WooCommerce tabs.

![](https://wpmozo.com/wp-content/uploads/2024/02/manage-default-tab-using-tab-manager.webp)

If you have edited the title for the default WooCommerce tab globally but want to change it at the product level, you can use the option present on the individual product page which will allow you to override the configuration for the default tabs. For example, if you have disabled the description tab globally in the tab manager, then on the specific product page, you can still enable the description tab using the option provided by the tab manager there.

![](https://wpmozo.com/wp-content/uploads/2024/02/tab-manager-setting-on-specific-product-page-2048x747.webp)

## **How to create new tab**

To create a new tab, navigate to the **Products Tabs** settings on your WordPress dashboard. Create a new tab and publish it. In the tab settings, you have options for tab status, content type, level, user role, and priority.

![](https://wpmozo.com/wp-content/uploads/2024/02/add-new-tab-using-tab-manager-for-woo.webp)

#### **Tab Status**

With the status setting, you can enable /disable the tab on the product pages.

#### **Content Type**

With this setting, you can select the content type. This could be current tab content, page content, and Elementor template. Elementor template content is only visible if the Elementor plugin is installed.

![](https://wpmozo.com/wp-content/uploads/2024/02/setting-panel-for-new-created-tab.webp)

#### **Level**

- Global: Displays the tab on all products.
- Product: Allows you to select specific products.
- Category: Allows you to select product categories.

![](https://wpmozo.com/wp-content/uploads/2024/02/product-level-visiblity.webp)![](https://wpmozo.com/wp-content/uploads/2024/02/tab-display-on-product-based-on-selected-categories.webp)

#### User Role

In the user role option, when you select a specific role, the tab will only be displayed if the user is logged in and assigned to that particular role.

## Enhance Gutenberg Page Building Experience With Advanced Blocks

With WPMozo Blocks and Addons, get feature-rich, user-friendly blocks that allow you to build webpage elements of different kinds using the Gutenberg editor. Install this free WordPress blocks plugin directly from the website and access tons of new and well-maintained blocks added to your Gutenberg blocks library.

Each block offers extensive features and options streamlining your web-building experience with the Gutenberg editor. Love to work on Gutenberg editor? This is the best Gutenberg blocks plugin to aid your creative fire—simply and beautifully.

## Before and After Image Slider Block

By using the Before After Slider Gutenberg block, you can display two variations of an image. It helps you showcase a comparison of a thing visually and interactively. For example, display a before and after image of a room renovated. You can add a horizontal or vertical slider; move the slider on hover or click, and apply other styles to make the slider look good.

![Before after image slider](https://wpmozo.com/wp-content/uploads/2025/04/wpmozo-before-after-image-slider.webp)

## Content Toggle Block

With the Content Toggle block, display your webpage content in a concise manner with a toggle switch. You can use this Gutenberg block to add content/blocks inside the content toggle and allow users to view it using the switch. For instance, create a monthly and yearly pricing table. Then, add it into the Content Toggle allowing users to easily switch and compare the plans.

![Content toggle](https://wpmozo.com/wp-content/uploads/2025/04/wpmozo-content-toggle.webp)

## Fancy Heading Block

The Fancy Heading block lets you add heading with PRE, MAIN, and POST heading text. You can customize them individually and showcase them for better engagement. The heading can also be stacked if you need to. Apply different color, text customizations, and more.

![Fancy heading](https://wpmozo.com/wp-content/uploads/2025/04/wpmozo-fancy-heading.webp)

## Fancy Text Block

The Fancy Text Gutenberg block lets you style text with a gradient color or Background Clipping (an image in the text.) If you use a snow-falling image, each letter will display the snow falling within it, making the text visually engaging. It’s a great addition to improving the text on your Gutenberg-based pages or posts.

![Fancy text](https://wpmozo.com/wp-content/uploads/2025/04/wpmozo-fancy-text.webp)

## Flip Box Block

Create flip boxes with two sides using Flip or 3D Cube effects, allowing movement in multiple directions. Adjust the flip speed to control the animation flow, add a 3D depth effect for a more dynamic appearance, and enhance the interaction with a shake-on-flip effect for added visual impact. This Gutenberg Block seamlessly integrates with the Gutenberg builder, making it easy to design interactive content sections.

![Flip box](https://wpmozo.com/wp-content/uploads/2025/04/wpmozo-flip-box.gif)

## Interactive Image Card Block

Display content on the image in various animation styles when the user hovers on the image card. This Gutenberg image block lets you add a Title and Content to the image, with extensive customization options. It comes with 10 animation styles to showcase the content on hover.

![Interactive image card](https://wpmozo.com/wp-content/uploads/2025/04/wpmozo-interactive-image-card.webp)

## Logo Slider Block

Use this Gutenberg block to create logo sliders to display your clients’ images or their brands on an interactive carousel. This block allows you to display and slide multiple logos at once, enable slide loop, pause on hover, use custom slider arrows, apply pagination, and much more.

![Logo slider](https://wpmozo.com/wp-content/uploads/2025/04/wpmozo-logo-slider.gif)

## Floating Image Block

Add floating animation to your images using the Floating Image block. It allows you to make the images float in different directions: Top to bottom, and left to right with custom speed control.

![Floating image](https://wpmozo.com/wp-content/uploads/2025/04/wpmozo-floating-image.gif)

## Tilt Image Block

With the Tilt Image Gutenberg block you can make the images tilt and show a 3D effect when users hover on them. In addition, you can also add a title, content, icon, and a button to add details and redirect users to a URL. Utilize its controls to maximize its effects like tilt rotation, speed, glare, 3D effect, and X/Y axis tilt disable.

![Tilt image](https://wpmozo.com/wp-content/uploads/2025/04/wpmozo-tilt-image.gif)

## Separator Block

Use this Gutenberg block by WPMozo to add styled separators on the page. You can display a Line separator with various styles or a Shadow separator. With the Line separator, choose to display Text, an Icon, or an Image.

![Separator](https://wpmozo.com/wp-content/uploads/2025/04/wpmozo-separator.webp)

The List block allows you to add customized lists with items having stacked or Inline layouts. Use the Image/Icon as a thumbnail for each individual list item with controls to customize them for Normal and Hover states. Improve entire lists look with Styles for Alignment, Item Text, Icon, Image, and Divider.

The product page of WooCommerce has three tabs: Additional Information, Reviews, and Descriptions. If you want to customize or add more tabs, you could use WPMozo Tab Manager for WooCommerce.

- Enable or disable the description, additional information, and reviews tab on the WooCommerce product page.
- Personalized the default tabs
- Add new custom tabs to the WooCommerce product pages.
- Display page content or Elementor templates with new custom tabs.
- Control the display of custom tabs on your online store.

Let’s look at the features that this WooCommerce Tab Manager plugin offers.

![WPMozo tab manager plugin](https://wpmozo.com/wp-content/uploads/2024/02/wpmozo-tab-manager-plugin.webp)

## Add new product tab

You can add new product tabs to your WooCommerce product pages next to the default WooCommerce tabs.

![Add new woo product tab](https://wpmozo.com/wp-content/uploads/2024/02/add-new-woo-product-tab.webp)

## Enable or disable the WooCommerce product tabs

Enable or disable existing description, additional information, reviews tab, and newly created tabs.

![Disable enable woo product tabs](https://wpmozo.com/wp-content/uploads/2024/02/disable-enable-woo-product-tabs.webp)

## Display page content and Elementor templates

Display the content of product pages and Elementor templates directly into the product tabs. This feature is useful when you want to showcase pages or Elementor templates with additional product information on tabs.

![Display elementor templates in woo product tabs](https://wpmozo.com/wp-content/uploads/2024/02/display-elementor-templates-in-woo-product-tabs.webp)

## Regulate tab display using levels

This WooCommerce Tab Manager plugin provides you the option to configure the display of tabs with Global, Product, and Category levels.

- “Global level” displays tabs on all product pages.
- “Product level” enables choosing specific products to show tabs.
- “Category level” assigns tabs to specific product categories.

![Regulate woo product tab levels](https://wpmozo.com/wp-content/uploads/2024/02/regulate-woo-product-tab-levels.webp)

## Control view with user roles

Allow and restrict the view of custom tabs to different logged-in users with user roles. Administrator, Editor, Author, Contributor, Subscriber, Customer, and Store Manager are the user roles that you can configure. It is possible to set up one or more user roles.

![Display controls woo product tabs](https://wpmozo.com/wp-content/uploads/2024/02/display-controls-woo-product-tabs.webp)

1. Log in to your [wpmozo.com](https://wpmozo.com/my-account/downloads/) account and navigate to the account area.
2. Locate the license key provided for plugin update.
3. **Copy the license key** to your clipboard.
4. Access your **WordPress admin area** (wp-admin).
5. From the dashboard, go to “ **WPMozo Wishlist**” and select “ **License**.”
6. In the license settings section **paste the license key**.
7. Click on the “ **Activate**“.

![](https://wpmozo.com/wp-content/uploads/2024/08/license-for-wpmozo-wishlist-for-woocommerce.webp)

By following these steps, you will successfully add your license key and activate the plugin, enabling you to receive seamless updates for your WPMozo product.

# Wishlists management

## **Dashboard Overview**

The **Wishlist Dashboard** is a dedicated panel that allows site administrators to manage all user-created wishlists efficiently. From this interface, admins can perform the following actions:

• **View Wishlists** – Access and review all wishlists created by users on the site.

• **View Wishlist Items** – Open individual wishlists to see the specific products or items users have added.

• **Delete Wishlists** – Remove unwanted or outdated wishlists as needed.

• **Sort Wishlists** – Arrange the list of wishlists based on the date they were created, in either ascending or descending order.

• **Set Display Preferences** – Control how many wishlists appear per page, optimizing navigation and management.

# Wishlist functionality configuration

The WooCommerce Wishlist plugin enables customers to create personalized wishlists of products they desire, making it easier for them to save and track their favorite items.

After installing the plugin, a new menu called **“WPMozo Wishlist”** appears in the WordPress admin panel.

![](https://wpmozo.com/wp-content/uploads/2024/08/wpmozo-wishlist-added-in-menu.webp)

This menu includes the following options:

- **Settings**: Configure wishlist functionalities.
- **Styles**: Customize the appearance of the wishlist.
- **Wishlist**: Manage user wishlists.
- **Popular**: View popular wishlist items.
- **License**: Manage licensing information.

![](https://wpmozo.com/wp-content/uploads/2024/08/wishlist-plugin-setting-menu-1-1024x143.webp)

## **How to create a wishlist page**

To display the wishlist on a page, use the following shortcode:

\[wpmozo\_wishlists\]

Copy and paste this shortcode onto a new page to display wishlists.

![](https://wpmozo.com/wp-content/uploads/2024/08/wishlist-code.webp)

## **Wishlist access and behavior**

### **Remove items from wishlist**

Enable the **“Remove from Wishlist on Second Click”** toggle to allow users to remove items by clicking the wishlist button again.

### **Enable wishlist for logged-in users only**

Navigate to the **Settings** panel and toggle the option **“Enable Wishlist for Logged-in Users Only”** to restrict wishlists to registered users.

### Enable Multiple Wishlist

This option allows users to create and manage more than one wishlist on your website.

**When enabled:**

- Users can organize their favorite products into different wishlists (e.g., “Birthday Gifts”, “Office Supplies”, “Wishlist for Kids”).
- A dropdown or option to select or create a new wishlist appears when a user adds a product.

**When disabled:**

- Users will have only a single wishlist where all saved products are stored by default.

### Choose Wishlist via

This option lets you decide how users will select a wishlist.

You can choose between:

#### **Dropdown**

- A small dropdown appears **right next to the heart icon** when clicked.
- Users can directly choose the wishlist from the dropdown without navigating away.

#### **Modal Popup**

This popup allows users to select an existing wishlist or create a new one.

Clicking the heart icon opens a **popup window** (modal).

![](https://wpmozo.com/wp-content/uploads/2024/08/wpmozo-wishlist-configuration.webp)

## **Wishlist button settings**

### **Wishlist button position on product page**

**Single Product Page**: **On Product Image**

Displays the wishlist button directly on the **product image**,.

**Before Add to Cart**

Places the button **above** the Add to Cart button.

**After Add to Cart**

Places the button **below** the Add to Cart button.

**Use Shortcode**

Gives you full control by allowing you to **manually place** the button using a shortcode.![](https://wpmozo.com/wp-content/uploads/2024/08/wishlist-button-on-product-page.webp)

- **Product Loop (Shop Page)**: Select the wishlist button position:
  - **On product image**
  - **Before Add to Cart**
  - **After Add to Cart**
  - **Use Shortcode**![](https://wpmozo.com/wp-content/uploads/2024/08/wihslist-button-loop.webp)

### **Customize wishlist button**

- **Single Product Page**: Choose between **Text, Icon, or Text & Icon**.
- **Product Loop**: Choose between **Text, Icon, or Text & Icon**.

### **Wishlist button position on product image**

On shop page, select whether the wishlist button appears on the **top right or top left** on the product image.

![](https://wpmozo.com/wp-content/uploads/2024/08/wishlist-button-position.webp)

## **Customizing wishlist notifications**

- **Add to Wishlist Button Text**: Set the label for the “Add to Wishlist” button.
- **Move to Wishlist Button Text**: Customize the “Move to Wishlist” button text on the cart page.
- **Added to Wishlist Notification Text**: Define the message displayed when an item is added.
- **Already in Wishlist Notification Text**: Change the default “Already in Wishlist” message.
- **Added to Wishlist Notification Text**: Change the default “Item Wishlisted” message.

![](https://wpmozo.com/wp-content/uploads/2024/08/notification-text-in-wishlist.webp)

## **Enabling multiple wishlists**

To allow users to create multiple wishlists, enable the **“Enable Multiple Wishlist”** option.

## **Customize wishlist creation text**

**Create Wishlist Text**: Define the text shown when users create a new wishlist.

![](https://wpmozo.com/wp-content/uploads/2024/08/option-for-create-new-wishlist.webp)

To add the Before After Slider block:

### Slider orientation and handle offset

You can customize the slider’s movement direction and position using these options:

- **Slider Orientation**: Choose between:
  - `Horizontal`
  - `Vertical`
- **Handle Offset**: Adjust the initial position of the slider handle using the slider or by entering a value manually.
- **Move Handle on Hover**: Enable this toggle to automatically move the handle when hovered.

![](https://wpmozo.com/wp-content/uploads/2025/04/slider-orientation-1-1024x466.webp)

### **Before section**

- **Select Image**: Upload or choose the image to be displayed as the “Before” image in the slider.

- **Show Label Only on Hover** _(Toggle)_: When enabled, the label appears only when the user hovers over the image.
- **Enter Label** _(Text field)_: You can type custom text here to display as the label for the Before image. Example: `"Before"`.

### **After section**

- **Select Image**: Upload or choose the image to be used as the “After” image in the slider.
- **Show Label** _(Toggle)_: Enables a visible label over the After image.
- **Show Label Only on Hover** _(Toggle)_: Shows the label only when the user hovers over the slider.
- **Enter Label** _(Text field)_: Custom text input for the After image label. Example: `"After"`.

![](https://wpmozo.com/wp-content/uploads/2025/04/add-before-after-image-block-1024x639.webp)

### Customize handle and overlay color

Styling options are available under the **General Style** tab:

- **Overlay on Hover**: Toggle the overlay effect when hovering over the slider.
- **Handle Color**: Set the color of the draggable handle.
- **Overlay Color**: Define the overlay tint color.

## Content toggle block settings

This section shows the configuration options for the **Content Toggle** block. It allows you to switch between two different content sections—ideal for scenarios like pricing plans (e.g., Monthly vs Yearly).

### Toggle one content

- **Toggle Title**: Set the label for the first toggle option (e.g., _Monthly_).
- **Icon**: Choose an icon to display alongside the title (optional).

### Toggle two content

- **Toggle Title**: Set the label for the second toggle option (e.g., _Yearly_).
- **Icon**: Choose an icon to display alongside the title (optional).

![](https://wpmozo.com/wp-content/uploads/2025/04/content-toggle-block-setting--980x473.webp)

## Adding content inside each toggle

Once you add the **Content Toggle** block and set titles for **Toggle One** and **Toggle Two**, you’ll see a **“+” (plus)** button inside each toggle section.

This allows you to insert content blocks (text, images, buttons, etc.) under each toggle.

For example, you can add pricing details under “Monthly” and “Yearly” toggle sections separately.

This flexible layout lets you display different content based on the selected toggle—perfect for comparisons, plans, FAQs, and more.

![](https://wpmozo.com/wp-content/uploads/2025/04/body-content-for-content-toggle.webp)

## Toggle switch settings

The **Toggle Switch** panel allows you to customize the appearance and behavior of the switch between the two toggle titles.

### **Switch type**

- **Rounded / Rectangle / Toggle** – Choose the shape of the toggle switch button.

### **Switch color**

- Customize the color of the toggle switch in both **Normal** and **Hover** states.

### **Color options**

- **Switch Color** – Color of the switch knob in normal state.
- **Switch Color (on state)** – Color of the switch knob when it’s toggled ON.
- **Switch Background** – Background color of the switch in the OFF state.
- **Switch Background (on state)** – Background color of the switch when toggled ON.

### **Switch alignment**

- Align the toggle switch and labels: **Left, Center, or Right**.

### **Dimensions**

- **Padding** – Adjust the spacing inside the toggle switch container.
- **Margin** – Adjust the spacing around the toggle switch block.

![](https://wpmozo.com/wp-content/uploads/2025/04/toggle-switch-configuration.webp)

## Toggle titles style settings

You can customize the look of both toggle titles (“Title One” and “Title Two”) using the following options:

- **Color**: Choose the text color for each title.
- **Typography**:
  - **Size**: Set the custom font size (in REM).
  - **Appearance**: Choose font weight like Regular, Semi Bold, Bold, etc.
  - **Letter Spacing**: Add space between letters (in pixels).
  - **Decoration**: Apply underline, strikethrough, or italic styles.
  - **Letter Case**: Transform text to UPPERCASE, lowercase, or Capitalize.

# Fancy Heading

The free Fancy Heading block lets you create eye-catching headings with advanced styling options, helping you enhance your content’s design and grab visitor attention.

![](https://wpmozo.com/wp-content/uploads/2025/04/fancy-heading-demo-on-documentation.webp)

## Adding the block

To add the Fancy Heading block:

1. Click the “+” button to add a new block.
2. Search for “Fancy Heading” and select it.
3. For more details refer to [this article](https://wpmozo.com/documentation/wpmozo-blocks-and-addons/add-block-to-a-page/).

## Heading content options

**Pre Heading** – Text that appears before the main heading.

**Main Heading** – Primary text, usually the focus.

**Post Heading** – Text that appears after the main heading.

**Display in Stack** – Toggle to display each part on a separate line.

![](https://wpmozo.com/wp-content/uploads/2025/04/fancy-heading-block-content-opiton--980x370.webp)

## Design options

In the **Fancy Heading block**, you can assign **different styles to each part** of your heading— **Pre**, **Main**, and **Post**—using the dedicated styling sections available.

![](https://wpmozo.com/wp-content/uploads/2025/04/design-options-in-fancyheading-wpmozo-block.webp)

### Global text settings

This section controls **common styling** that applies to the entire heading block (Pre + Main + Post), unless overridden by individual settings.

- **Color**
  - **Text Color**: Choose the default font color for your entire heading.
  - **Background Color**: Set a background color behind the entire heading.
- **Heading Alignment**
  - Align your heading text **Left**, **Center**, or **Right** using alignment icons.
- **Heading Level**
  - Choose the semantic HTML heading tag:
    - H1, H2, H3, H4, H5, or H6
  - This helps define heading structure for SEO and accessibility.

![](https://wpmozo.com/wp-content/uploads/2025/04/global-text-setting-option-in-wpmozo1.webp)

### **Pre text settings**

This section controls styling for the optional **introductory part** of the heading (e.g., “Use” in “Use Different Color”).

- **Pre Text Color**
  - Customize **Normal** and **Hover** text and background colors.
- **Pre Text Alignment**
  - Align left, center, or right independently of the block’s global alignment.
- **Typography**
  - **Size (Custom)** – Adjust size using VW (viewport width) or PX.
  - **Appearance** – Choose font weight like _Normal_, _Bold_, etc.
  - **Letter Spacing** – Add spacing between characters.
  - **Decoration** – Add _Underline_, _Strikethrough_, or _Italic_ styles.
  - **Letter Case** – Convert text to UPPERCASE, lowercase, or Capitalized.
  - **Line Height** – Adjust vertical spacing between lines of pre-text.

### **Post text settings**

This section styles the **ending part** of the heading (e.g., “Color” in “Use Different Color”).

- **Post Text Color**
  - Separate color settings for **Normal** and **Hover** states.
- **Post Text Alignment**
  - Independent alignment control for just the post text.
- **Typography**
  - Same detailed controls as in Pre Text:
    - Font size, weight, spacing, decorations, case, and line height.

### **Main text settings**

This section is for styling the **core part** of your heading (e.g., “Different” in “Use Different Color”) and is often the most visually prominent.

- **Main Text Color**
  - Full control over **Normal** and **Hover** states for both text and background.
- **Main Text Alignment**
  - Align the main word differently if needed.
- **Typography**
  - All advanced options like:
    - Font size (customizable in VW), bold/italic/underline, letter spacing, text case, and line height.

![](https://wpmozo.com/wp-content/uploads/2025/04/pre-post-and-main-text-setting-in-wpmozo-block.webp)

- **Shake On Flip**: When enabled, the Flip Box will have a subtle shake effect during the flip animation to make the interaction more engaging.

## Flip box content settings

This section allows you to configure the content shown on each side of the Flip Box:

- **Front / Back Tabs**: Toggle between editing the front and back sides of the Flip Box.
- **Title**: Enter the heading text that will appear on the selected side.
- **Content**: Add descriptive text for the selected side.

## Flip box elements settings

This panel allows you to add and configure visual elements on the front or back side of the Flip Box:

- **Front / Back Tabs**: Select which side of the Flip Box you’re customizing.
- **Element Type**: Choose what type of element to display:
  - **None** – No element will be shown.
  - **Icon** – Displays a selected icon.
  - **Image** – Allows you to upload an image instead.
- **Icon**: If “Icon” is selected as the element type, choose your preferred icon from the dropdown.

## Global styling settings

Use the Global Styling panel to customize the overall appearance of the Flip Box:

- **Content Width**: Adjust the width of the content area using the slider or input box.
- **Color Settings**:
  - Choose colors for the **Title** and **Content** separately.
  - Use the toggle below to switch between styling Title or Content.
- **Typography**:
  - **Size**: Set the font size.
  - **Appearance**: Select the font style (e.g., Default, Bold, Italic).
  - **Letter Spacing**: Define spacing between characters (in pixels).
  - **Decoration**: Apply underline, strikethrough, or no decoration.
  - **Letter Case**: Choose between uppercase, lowercase, capitalized, or default.
  - **Line Height**: Adjust vertical spacing between lines of text.

### FlipBox style settings

Use the FlipBox Style panel to customize the design of both the front and back sides of the Flip Box:

- **Side Selection**: Toggle between **Front** and **Back** to apply different styles to each side.
- **Heading Level**: Choose the heading tag (H1–H6) for the title element.
- **Color Settings**:
  - **Title Color** and **Content Color**: Customize text colors individually.
  - **Background Color**: Set a background color for the selected side.
- **Style Target**: Switch between **Title** and **Content** to apply typography styles.
- **Typography**:
  - **Size**: Enter a custom font size (in pixels).
  - **Appearance**: Choose text style such as Bold or Italic.
  - **Letter Spacing**: Adjust spacing between letters.
  - **Decoration**: Apply underline, strikethrough, or none.
  - **Letter Case**: Set text to uppercase, lowercase, capitalized, or default.
  - **Line Height**: Control vertical spacing between lines.

### **FlipBox image/icon style**

This section allows you to customize the image or icon used in the FlipBox module. You can style either the **Front** or **Back** side by toggling between the two tabs.

- **Front / Back Tabs**

Switch between styling the front or back face of the FlipBox.
- **Color**

Select the icon color using the color picker provided.
- **Icon Size**

Adjust the size of the icon using the slider or input field (in pixels).
  - Use the **Reset** button to revert to the default size.
- **Image/Icon Placement**

Choose the position of the image or icon. Options include: `Top`, `Bottom`, `Left`, or `Right`.
- **Style Icon (Toggle)**

Enable this option if you want to apply additional styles to the icon such as padding, borders, or background.

### **FlipBox content alignment**

This setting allows you to control the horizontal and vertical alignment of the content inside the FlipBox. You can adjust the alignment separately for the **Front** and **Back** sides by selecting the appropriate tab.

- **Content Alignment**: Align the text or content to the left, center, or right within the FlipBox.
- **Vertical Alignment**: Position the content at the top, center, or bottom vertically within the FlipBox area.

### **FlipBox border**

This section allows you to customize the border appearance for both the **Front** and **Back** sides of the FlipBox.

- **Border**: Adjust the width of the border using the slider or input field. You can also unlink the values to set different border widths for each side.
- **Radius**: Define the border radius to create rounded corners. This helps soften the box edges and enhance the visual style.

### **FlipBox padding**

This panel lets you adjust internal spacing (padding) within the FlipBox. Use the sliders to set padding values around the content area. The settings can be customized individually for each side top, bottom, left, and right and separately for the front and back of the box.

# How do I troubleshoot common plugin-related issues?

When facing common plugin-related issues, you can follow these steps to troubleshoot and resolve the problems:

1. **Check for plugin conflicts**: Deactivate other plugins one by one to identify if any conflicts are occurring between plugins. Reactivate each plugin after testing to determine the specific plugin causing the issue.
2. **Review error logs**: Examine the error logs of your website to identify any error messages or warnings associated with the plugin. These logs can provide valuable insights into the root cause of the issue.
3. **Clear cache**: Clear any caching mechanisms in place, including browser cache, caching plugins, or server-side caching. This ensures that you are viewing the most recent version of your website and plugin files.
4. **Monitor system resources**: Insufficient resources can sometimes lead to plugin-related issues. Ensure that your hosting environment meets the recommended requirements.

If the issue persists after trying these steps, don’t hesitate to reach out to our support team. Provide them with detailed information about the problem, including steps to reproduce it, error messages, and any relevant system configurations.

By following these troubleshooting steps, you can effectively identify and resolve common plugin-related issues. It’s essential to keep your plugins up to date to benefit from bug fixes and improvements provided by the developer.

**How to Get Updates for Your Plugin**
