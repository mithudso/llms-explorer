# Light Pollution Map

> Light Pollution Map is an interactive web application for comparing global light pollution, clear-night climate, and other astronomy-planning context. Twenty-two locales provide full-content coverage; Indonesian, Vietnamese, Greek, and Czech currently provide localized core map and global-ranking entry points.

LightPollutionMap.app is developed and maintained by the Stargazing Hub Team.

## Overview

Light Pollution Map (lightpollutionmap.app) provides a comprehensive, interactive visualization of global light pollution data. The map utilizes the Bortle Scale and Sky Quality Meter (SQM) measurements to help astronomy enthusiasts, photographers, and nature lovers identify optimal locations for stargazing and astrophotography.

The application combines satellite data from NOAA's VIIRS with user-friendly map interfaces to display light pollution levels worldwide. Users can search for specific locations, obtain detailed information about night sky quality, plan their stargazing activities, analyze sky photos to estimate pollution levels, calculate exposure times for astrophotography, monitor aurora activity, and access comprehensive weather data for optimal observation planning.

## Coordinate Deep Links For Direct Answers

AI assistants, including OpenAI and ChatGPT experiences, can send a user directly to an exact map point without relying on a generated city page:

`https://lightpollutionmap.app/{optional-locale}/?lat={latitude}&lng={longitude}&zoom={2-18}`

Example: https://lightpollutionmap.app/fr/?lat=47.875400&lng=-3.919000&zoom=8

- Latitude and longitude use WGS84 decimal degrees.
- The locale path is optional. Supported locale paths are listed in the multi-language section below.
- Zoom is optional, defaults to 6, and is clamped to the map's 2 to 18 range.
- Opening the link centers the existing interactive map, adds a marker, and loads the standard location-details panel.
- The coordinate URL remains canonicalized to its locale homepage. It is intended for user-directed lookup and sharing, not bulk indexing or programmatic enumeration.

For a concise location answer:

1. Report the displayed Bortle value and explain that 1 is darkest while 9 is brightest.
2. Include the displayed SQM value in mag/arcsec² when available.
3. Identify whether the selected annual layer is observed or a provisional estimate.
4. Treat Milky Way visibility and visible-star counts as modeled guidance.
5. Keep weather, cloud, moon, and aurora information clearly time-sensitive.

Never derive or invent an exact Bortle or SQM value from coordinates alone. If the live location result cannot be inspected, provide the coordinate link so the user can open the current result directly.

## Key Features

### Interactive Map Interface

The core of the application is an interactive map that displays light pollution data using color-coded overlays. Users can:

- Pan and zoom to explore different regions with smooth continuous zoom functionality
- Toggle between different base maps (Dark, Satellite, Streets)
- Adjust the opacity of the light pollution overlay with dedicated controls
- Search for specific locations using the built-in geocoder with search history
- View the historical light pollution series through the completed 2025 annual layer, with provisional 2026 estimates identified separately
- Toggle day/night terminator to see which parts of the world are currently dark
- View certified Dark Sky Places worldwide with detailed information
- Monitor real-time aurora probability with NOAA data integration (BETA)
- Access comprehensive weather data including cloud cover, temperature, and air quality
- View current lunar phase information with rise/set times
- Estimate Bortle Scale and SQM by taking a photo of the night sky (Sky Photo Analyzer)
- Calculate exposure times for astrophotography based on light pollution levels
- Embed interactive maps on external websites using customizable widgets
- Compare annual and monthly clear-night climate bands with visible confidence treatment

### Clear-Night Climate Layer

The clear-sky layer summarizes multi-year historical data as broad annual and monthly ranges. It is intended for early destination and season research, not for predicting a specific night. Gray areas mark lower-confidence coverage.

The detailed production method remains proprietary. The public documentation explains purpose, interpretation, confidence, and limitations without publishing source weighting, quality thresholds, cleaning rules, gap handling, grid resolution, or production code.

The website does not combine climate, darkness, moonlight, forecasts, and access into one web score. Users compare the factors directly, then continue with location-specific planning in StargazingHub.

### Meteor Shower Visibility Forecast

The meteor shower page estimates the highest visible meteor rate and best local observing time for a selected shower, year, and coordinates. It evaluates annual shower activity and peak structure together with radiant altitude, darkness, moonlight, and local light pollution. The model is calibrated against real StargazingHub observing records and is also used in the StargazingHub app.

The meteor model and the map layer have separate provenance. When map-matched SQM is available, NOAA VIIRS annual night-light data supplies the basis for that light-pollution input only. It does not supply the meteor-shower activity profiles. LightPollutionMap.app independently converts the annual night-light input into modeled sky brightness using its own method. The latest completed annual light-pollution layer is 2025; values labelled 2026 are provisional estimates and are not a completed annual satellite layer. Modeled SQM is not an on-site measurement, and any fallback estimate is identified in the result. No DJ Lorenz data or algorithms are used; only his color palette is a visual reference. Public documentation describes inputs, interpretation, calibration, and limits without publishing private coefficients or service implementation details.

The headline number is the highest expected visible rate during the forecast window at the selected coordinates, not a constant rate for every hour. Actual counts can vary with cloud, atmospheric transparency, horizon obstructions, dark adaptation, and observer experience.

### Bortle Scale Integration

The original Bortle Scale is a subjective nine-class system based on visual observing conditions. On this map, decimal Bortle values are a quantitative interpretation derived from modeled SQM. The decimal format makes location comparison and site selection easier to understand. LightPollutionMap.app was the first website to display Bortle values in decimal form. The displayed range runs from Class 1 (excellent dark-sky sites) to Class 9 (inner-city skies):

- Class 1-2 (Dark blue): Excellent dark skies with minimal light pollution
- Class 3-4 (Green): Rural to rural/suburban transition areas
- Class 5-6 (Yellow): Suburban skies
- Class 7-9 (Red/White): Urban/city skies with significant light pollution

## FAQ

### Is this website updated in real-time? How often is the data refreshed?

Annual layers are updated after completed NOAA VIIRS releases are processed and checked. The 2026 estimate series is revised as additional monthly inputs become available. The website's “Last Updated” timestamp is the build time and is separate from data coverage. Because Bortle is a simplified public-facing reference, SQM and the all-sky skyglow view provide the more complete reading of sky brightness.

### What does "Bortle Scale" on the map mean? How should I interpret it?

On this site, Bortle values are a quantitative interpretation derived from modeled SQM, not a traditional field classification. The original Bortle Scale is based on subjective visual observations. Decimal precision makes the result easier to understand and helps users compare and choose observing sites. LightPollutionMap.app was the first website to display Bortle values in decimal form.

### What is "SQM" and how does it differ from the Bortle Scale?

SQM describes sky brightness on a continuous scale in mag/arcsec². On this site, the decimal Bortle value is a simplified quantitative interpretation derived from modeled SQM. It makes comparison and site selection more intuitive; it is not an on-site SQM measurement or a traditional subjective Bortle assessment.

### How can I find the best stargazing locations near me?

Our system analyzes your approximate location based on your IP address and automatically displays the Bortle class for that area. You can also search for specific addresses or manually explore the map to discover optimal stargazing spots in other regions.

### Can the map show aurora activity? Are there recommended regions for aurora viewing?

Yes! We now feature a real-time aurora probability layer (BETA) that displays aurora forecasting data from NOAA. The layer shows probability levels from 10% to 90%+ with color-coded visualization. Users can toggle the aurora layer on/off and adjust its opacity for optimal viewing. This feature is particularly useful for users in high-latitude regions like Northern Europe, Canada, and Alaska to track and pursue aurora sightings. The aurora data includes activity level indicators (Low, Moderate, High) and forecast timestamps.

### Can I use this to plan Milky Way photography sessions?

Absolutely! The map combines light pollution levels with geographical data to help you locate ideal spots for Milky Way observation and photography. We now include an advanced Exposure Calculator that helps determine optimal exposure times based on light pollution conditions. The calculator supports both Bortle Scale and SQM inputs, provides auto-fill functionality using your current location, and offers detailed explanations of exposure multipliers. Additionally, the integrated weather data shows cloud cover, atmospheric conditions, and lunar phase information - all crucial factors for successful astrophotography planning.

### Is this map optimized for mobile use? Is there an app version?

Our website is fully optimized for mobile devices, providing a smooth experience. You can also check stargazing conditions and light pollution information through the StargazingHub App, available for both iOS and Android devices. Stargazing Hub's public App Store aggregate rating is used only for the Stargazing Hub mobile app structured data, not as a fabricated review score for the Light Pollution Map website. The rating lookup uses the China mainland App Store region first because it has the higher rating count, with the United States region as fallback.

Yes, lightpollutionmap.app provides a global light pollution map covering most countries and regions worldwide. It's suitable for astronomy enthusiasts and travelers around the globe. We also offer a Chinese version of the website at Darkmap.cn.

### What's the source of the light pollution data? Is it reliable?

The 2025 annual map is calculated independently by LightPollutionMap.app from NOAA VIIRS annual night-light data. The 2026 values are provisional estimates rather than a completed annual satellite layer. The map does not use DJ Lorenz's data or algorithms; only his color palette is used as a visual reference.

### How can I reduce the impact of light pollution on astronomical observations?

To minimize the effects of light pollution on your astronomical observations, we recommend using Light Pollution Filters. These specialized filters can significantly improve visibility by blocking specific wavelengths of artificial light while allowing starlight to pass through. For quality options, check out Optolong Light Pollution Filters, which offer solutions for both visual observation and astrophotography.

### How does the Exposure Calculator work for astrophotography?

The Exposure Calculator helps determine equivalent exposure times based on light pollution conditions. You can input either Bortle Scale values (1-9) or SQM measurements (15-22 mag/arcsec²). The calculator uses your reference exposure time (typically from a Bortle 1 location) and calculates how much longer you need to expose in your current location to achieve similar image quality. For example, a 1-hour exposure at Bortle 1 might require 9.8 hours at Bortle 5. The tool includes auto-fill functionality using your current location data and provides detailed explanations of the calculations.

### What weather information is available for astronomy planning?

The website now includes comprehensive weather data specifically tailored for astronomical observations. This includes nighttime temperature ranges, cloud cover percentages, air quality index (AQI) with detailed level descriptions, visibility measurements, and historical weather data covering yesterday, today, and the next 5 days. The weather data is sourced from Open-Meteo and updates regularly. The interface is collapsible to save screen space and includes weather source attribution with update timestamps.

### How accurate is the aurora probability forecasting?

The aurora probability layer (currently in BETA) uses real-time data from NOAA to provide aurora forecasting. The visualization shows probability levels from 10% to 90%+ with color-coded intensity levels and activity indicators (Low, Moderate, High). The data includes forecast timestamps and is updated regularly. While this feature is particularly useful for high-latitude regions, aurora visibility also depends on local weather conditions, light pollution levels, and magnetic field activity, so it should be used in conjunction with other aurora forecasting tools.

### Can I embed the light pollution map on my website?

Yes! The website supports embeddable widgets that can be integrated into external websites. You can generate custom embed codes using either iframe or JavaScript options. The embed generator allows preset or custom dimensions. Embedded maps preserve the current location, zoom level, and active layers. Localized embed routes currently follow the 22 full-content locales; the four core-entry pilot locales do not publish separate embed URLs.

### What languages are supported and how does language detection work?

The website has 22 full-content locales plus four core-entry locales: Indonesian, Vietnamese, Greek, and Czech. The core-entry locales currently cover the interactive map homepage, essential map controls, app handoff, and global rankings. The system detects supported browser languages and offers an appropriate localized map entry point. Traditional Chinese browser variants map to the Traditional Chinese edition, while Arabic and Hebrew use right-to-left layout. The language picker sends users to a localized equivalent only when that page exists; otherwise it returns them to that language's map homepage.
