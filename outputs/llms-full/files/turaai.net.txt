## What Tura is

Tura is an open-source agent runtime harness for repository work. It is designed around macro command execution, explicit task state, backward reasoning, prompt and context management, and verification-oriented development workflows. Tura can be used through terminal and graphical interfaces and can connect to configured model providers.

Tura is a developer tool, not a foundation model or model provider. Users supply or configure supported model-provider access separately. Installation does not itself provide an API key, provider subscription, or model entitlement.

## Product concepts

### Macro command execution

Tura exposes a structured `command_run` workflow that can group dependent or parallel repository operations. Its goal is to reduce unnecessary model round trips while retaining concrete execution and verification steps.

### Task state and context management

Tura keeps explicit task status and supports context compaction so an agent can resume work with a concrete execution record instead of reconstructing the entire state from conversation alone.

### Backward reasoning

Tura prompts the agent to reason from required end conditions toward the current state, with the intent of identifying constraints and failure paths before implementation.

### Verification

The project emphasizes repository-aware checks, test-driven workflows, and evidence attached to completed changes. These are system design goals; individual outcomes still depend on the configured model, task, repository, and environment.
