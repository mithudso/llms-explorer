## Problems, failure modes and limitations

- [statement] Configure string fields in encryptedFields.fields with path, bsonType: "string", and queries.queryType set to "prefix", "suffix", or "substring". Prefix and suffix may coexist on one field; substring cannot be combined with another query type on that field. (high confidence) — https://www.mongodb.com/docs/manual/core/queryable-encryption/qe-create-encryption-schema.md · keywords: Queryable Encryption prefix, suffix and substring query configuration · also: https://www.mongodb.com/docs/manual/core/queryable-encryption/fundamentals/encrypt-and-query.md, https://www.nosqlbooster.com/blog/announcing-nosqlbooster-11-2/
- [statement] For GA substring queries, strMaxLength is required and must be 2–50 inclusive; strMinQueryLength must be at least 2; strMaxQueryLength must be 2–6 inclusive. Prefix and suffix query length bounds start at 1. Inserts or queries beyond configured bounds fail. (high confidence) (verified as of 2026-10-14) — https://www.mongodb.com/docs/manual/core/queryable-encryption/fundamentals/encrypt-and-query.md · keywords: Queryable Encryption prefix, suffix and substring query configuration · also: https://www.mongodb.com/docs/manual/core/queryable-encryption/qe-estimate-storage-impact.md
- [statement] For preview migration, a compatible 9.0 driver can decrypt existing data by reading the whole collection or filtering an unencrypted field. It cannot run preview encrypted-field queries. mongoexport and mongodump do not perform the required decryption. ## Comparisons and alternatives

- [statement] The storage guide models worst-case tags per field as 1 + (strMaxQueryLength - strMinQueryLength + 1) for prefix or suffix. At substring limits 2–6 with strMaxLength 50, its example produces 236 tags versus 6 for prefix or suffix. These are upper-bound estimates. (low confidence) — https://www.mongodb.com/docs/manual/core/queryable-encryption/qe-estimate-storage-impact.md
- [statement] Choose the smallest useful query-length interval before creating the encrypted collection. Substring indexes generate more search tags than prefix or suffix indexes, and their field-length bound also affects storage. MongoDB recommends substring only when prefix/suffix are insufficient, generally on one field and collections below 50 million documents; these are sizing recommendations rather than stated hard collection limits. (high confidence) (verified as of 2026-10-14) — https://www.mongodb.com/docs/manual/core/queryable-encryption/fundamentals/encrypt-and-query.md · keywords: Queryable Encryption prefix, suffix and substring query configuration · also: https://www.mongodb.com/docs/manual/core/queryable-encryption/qe-estimate-storage-impact.md
