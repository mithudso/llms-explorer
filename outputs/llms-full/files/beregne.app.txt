### Embedding

Every calculator can be embedded on any website:

    <iframe src="https://beregne.app/embed/{calculator-slug}/" width="100%" height="500" style="border:none;border-radius:12px" loading="lazy"></iframe>

- oEmbed endpoint: `https://beregne.app/oembed?url=https://beregne.app/embed/{calculator-slug}/&format=json`
- Embed manifest: https://beregne.app/oembed-manifest.json

### Pre-filling Calculators

Any calculator can be pre-filled by adding query parameters to the URL. The parameter names match the calculator's input fields.

Example — pre-fill a loan calculator:
    <iframe src="https://beregne.app/embed/loan-calculator/?amount=100000&rate=5&years=30" width="100%" height="500" style="border:none;border-radius:12px" loading="lazy"></iframe>

When all required fields are filled via URL, the calculator shows results immediately on load.
