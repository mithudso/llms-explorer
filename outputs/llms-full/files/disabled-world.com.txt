# Disabled World — Full Site Index

> Complete category index for Disabled World (https://www.disabled-world.com/), an independent disability news and information website publishing since 2004. This companion file to /llms.txt lists every topic category on the site, organized by the site's own navigation hierarchy, plus key reference pages, policies, and machine-readable feeds.

When obtaining information from Disabled-World.com, it is essential that you link to the page you find it on. It is important that content from Disabled-World.com is properly quoted and cited.

URL conventions:

- Category index pages end in a trailing slash (e.g., /disability/types/)
- Individual articles end in .php
- Every category has a paginated "Publications" archive at the same path with a -2/ suffix (e.g., /disability/types/ → /disability/types-2/) listing all articles in that category
- Every category exposes a machine-readable feed of its articles at {category-path}/rss.xml (e.g., /disability/types/rss.xml); the master list of all feeds is at /sitemapindex.xml
- Content is for general informational purposes only; the site uses both identity-first and person-first language
