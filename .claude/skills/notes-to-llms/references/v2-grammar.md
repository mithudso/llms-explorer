# The spec-v2 file grammars, and the bars they are judged by

<!-- notes-to-llms · references/v2-grammar.md · 2026-09-01 -->

Every code, severity and number here was read out of `hub/scripts/llms_lint.py` and
`hub/scripts/docset_refine/{export_llms,topical}.py`. If those files change, this one is
wrong: check them, and trust them over this page.

One distinction worth keeping straight, because getting it wrong makes a green lint look
like more than it is. `llms_lint.py` runs the **deterministic** passes only — its own
docstring says the model and live passes "live in the skill". So `P4` (navigation), `P8`
(facts truth), `P11`–`P13` (including `H3`, serving headers) are `/ldo` passes, not
anything this gate can tell you about.

## 1. What spec v2 actually requires (2026-08-10)

The spec got *looser*; the quality bar did not. Source:
`skills/document-formats/references/llms-txt.md` §2 and `docs/site/components/11-v2-vs-v1.md` §3a.

| Rule | v2 says | What still judges it |
|---|---|---|
| Required elements | **H1 only** | a blockquote too: its absence is `P1 I2` Medium (quality, not validity) |
| Placement | root **or any subpath**; most-specific wins | enables split roots and families |
| Discovery | `Link: <…>; rel="describedby"` on the file; `rel="alternate"; type="text/markdown"` on HTML pages | `P13 H3` Low — a **live** `/ldo` pass, not in `llms_lint.py` |
| Markdown twins | `page.html.md` **or** `page.md` | either passes |
| `## Optional` | a *convention* for secondary material; nothing mechanical consumes it | keep it last: `P1 N4` Medium |
| BOM | tolerated | `P14 H1` strips it as hygiene |
| Consumption | "view or search the index, then follow links" | the size ladder is the producer's job |

The v1 mechanic that is **gone**: `llms_txt2ctx` and context expansion. Do not design for
a consumer that inlines the whole file.

## 2. `llms.txt` — the index

```
# <Subject>

> <what it is · who it is for · verified-as-of YYYY-MM-DD>

<!-- generated by notes-to-llms v1 · from N notes / M pages · YYYY-MM-DD · verified-as-of YYYY-MM-DD -->

## <Section>

- [<name>](/my-notes/limits.md): <10–25 words, extractive, naming the exact tokens>
- [Claims for this section](llms-facts.txt#rate-limits): <…>

## Shared

- [Glossary and errors](llms-facts.txt#shared): <…>

## Optional

- [Older drafts](llms-facts.txt#optional): <…>
```

| Bar | Value | Finding |
|---|---|---|
| Index size | ≤ **10 000 bytes** (`INDEX_MAX_BYTES`); split hub-and-spoke above it | `P5 S1` Medium |
| Hard ceiling | **100 000 bytes** (`INDEX_HARD_BYTES`): "a full file wearing the wrong name" | `P5 S1` **High** |
| Blockquote | present, and not a restatement of the H1 | `P1 I2` Medium |
| Headings | H2 only; no H3+, and no prose after the first H2 beyond list notes | `P1 I4` Medium for an H3+ or a stray paragraph; Low when links are not grouped under an H2 at all |
| Description present | **every** link. High when > 40 % are missing **and** ≥ 3 are missing | `P3 D1` |
| Description length | **10–25 words** (`DESC_WORDS`); ≤ 5 % may fall outside | `P3 D3` Low |
| Description content | must not be a literal restatement of the link name | `P3 D2` Medium |
| Description uniqueness | no two identical | `P3 D4` Medium |
| No ellipsis | descriptions are written, not truncated | `P3 D3` Low |
| Duplicate link targets | none across sections | `P2 N7` Low |
| `## Optional` | last section | `P1 N4` Medium |
| Provenance banner | HTML comment in the first 4000 chars naming `generated` / `verified-as-of` | `P9 P1` Medium |

`MAX_DESC_CHARS = 180` is the generator's truncation point; write inside the 10–25 word
band and it never bites.

**`P3 D2` is narrower than it sounds.** It flags only an exact, case-insensitive match
between the description and the link name. A description that could have been written
without reading the page passes it. Extractiveness is a judgement, made by `/ldo` P4 or by
you — never by a green lint.

**`P3 D6`** (page/token/unit counts on link lines) applies to **family** files only, and
`COUNTS_RE` is satisfied by **any one** of pages, tokens or units.

## 3. `llms-facts.txt` — the claims

```
# <Subject> — facts

> Source-anchored units extracted from N notes: <count> across <pages> pages.
> Each line ends in the page URL and anchor it came from.

## Rate limits
</my-notes/limits.md>

- [statement] The gateway allows 60 requests per minute per key — /my-notes/limits.md#rate-limits
- [actionable] Absorb bursts with a token bucket refilling every second — /my-notes/limits.md#burst · keywords: token bucket, burst · verified-as-of: 2026-09-01
- [problem] A 429 means the bucket is empty; back off rather than retry — /my-notes/errors.md
```

The line grammar `UNIT_RE` parses, and nothing else:

```
- [<type>] <text> — <source>[ · keywords: a, b][ · verified-as-of: YYYY-MM-DD]
```

Only `keywords:` and `verified-as-of:` are legal after a ` · `. **An `also:` field breaks
the match**, and a line that does not match is counted unsourced — a High. Carry a second
source in `keywords:`, or emit a second unit.

| Bar | Value | Finding |
|---|---|---|
| Source on every line | must start with `http`, `/` or `.` | `P7 C6` **High** |
| Any unit lines at all | ≥ 1 | `P7 C6` **High** |
| Type in `UNIT_TYPES` | the 12 below | `P7 C6` Medium |
| Unit length | ≤ 2 sentences **and** ≤ 400 chars; ≤ 10 % may exceed | `P7 C6` Medium |
| Anchor resolves in the mirror | pass `--mirror`; High above 20 % unresolved, else Medium | `P7 R3` |
| facts ÷ full size ratio | Low above 0.15, Medium above 0.30 | `P5 S4` |

`UNIT_TYPES` — `concept`, `fact`, `actionable`, `question`, `problem`, `statement`,
`quote`, `idea`, `snippet`, `parameter`, `definition`, `change`.

Ordering inside a section: `definition`/`concept` first, then `statement`/`parameter`,
then `actionable`/`snippet`, then `fact`/`problem`/`change`.

**Two traps specific to note-derived facts.**

1. **Anchors are ATX-only and de-duplicated into a set.** `_mirror_headings` builds
   `{url: {"#slug", …}}` with an ATX regex. A setext heading contributes nothing (the
   normaliser converts them), a repeated heading contributes one slug (so `#burst-2`
   resolves to nothing), and a page with no headings contributes an *empty set* — which
   means any anchor on it is unresolved. Units from such a page carry the bare page URL.
2. **The `<url>` page line only counts for `http`.** `pass_facts` records a page URL only
   from a line matching `<http…>`, so with root-relative sources the "indexed page with
   no units" coverage check cannot fire. Do that coverage check yourself, from the
   inventory, rather than expecting the gate to catch it.

## 4. `llms-full.txt` and `llms-small.txt` — the ladder

Mintlify grammar, one block per page, header comment naming the grammar:

```
# <Title>
Source: <url>

<body>
```

| Bar | Value | Finding |
|---|---|---|
| Header comment naming the grammar | present | `P6 C1` Low |
| Blocks actually parse | ≥ 1 | `P6 C1` **High** |
| `llms-small.txt` beside any `llms-full.txt` | required | `P5 S2` Medium |
| `llms-small.txt` budget | ≤ **200 000 chars** (~50k tokens, the Cursor-stability ceiling) | `P5 S3` Medium |
| Per-block size | ≤ 200 000 bytes | `P6 S6` Low |
| Duplicate blocks (same source URL) | none | `P6 C5` Medium |
| Nav/MDX residue lines | none | `P6 C3` Medium |
| Unclosed code fences | none | `P6 C4` Medium |
| Untagged fences | tagged | `P6 C4` Low |

`llms-small.txt` is reference-class pages first, then guides, until the budget is spent.
Publish only full text you have the right to publish: third-party bodies stay internal,
and `P9 P3` is a **High** on third-party full text without an `<!-- internal -->` marker.
Pass `--third-party` at the gate when that is the situation.

## 5. `manifest.json` — the real shapes

Do not invent one. `P5 H8` reads `m.get("files", m)[<name>]["bytes"]`, so a manifest in an
invented shape does not fail the check, it *disables* it.

`docset_refine export` writes:

```json
{
 "docset": "my-notes", "host": "", "title": "…", "pages": 37,
 "acquired": null, "chars_per_token": 4,
 "files": {"llms.txt": {"bytes": 4210, "tokens": 1052},
           "llms-facts.txt": {"bytes": 18004, "tokens": 4501}},
 "units": 214, "sections": ["Guides", "Overview"],
 "dropped_empty_pages": 2,
 "overrides": {"title": "…", "summary": "…", "section_order": ["…"], "note": "…"}
}
```

`docset_refine topical` writes a different one, and it is the better one for notes:

```json
{
 "kind": "topical", "subject": "Rate limiting", "title": "…", "slug": "rate-limiting",
 "generated": "2026-09-01", "pool": ["…/all_units.jsonl"],
 "units": 214, "sources": 37, "rejected": 6,
 "sections": {"Burst control": {"slug": "burst-control", "facts": 22, "frontier": false}},
 "shared": 8, "assignment": {…}, "types": {"statement": 88, …},
 "files": {"llms.txt": {"bytes": 4210, "tokens": 1052}, "llms-facts.txt": {…}},
 "overrides": {…}
}
```

`OVERRIDE_KEYS` = `title`, `summary`, `section_order`, `note`. Nothing else survives a
regeneration, so anything else the user wants kept has to change the *inputs*.

`topical` also writes **`<out>/pool.rejected.jsonl`**, one record per dropped line:
`{"file": "all_units.jsonl", "line": "<first 120 chars>", "reason": "unsourced"}`. Reasons
it emits are `unsourced`, `bad json` and `bad fact line`. On the hand-written route, write
the same file, in the same shape, with your own reasons appended.

## 6. Hygiene (`P14 H1`)

UTF-8 without BOM · LF line endings · no tabs in list lines · no trailing whitespace ·
exactly one trailing newline · no smart quotes or zero-width characters inside a URL —
that last one is a **High**, because it produces a link that looks right and resolves
nowhere.

## 7. Secrets (`P9 P5`)

A credential pattern in the text is a **High** and blocks publishing; a placeholder
(`YOUR_API_KEY`, `sk-xxx`) is a Low. Run the gate before publishing, not after, and if a
real credential surfaces, drop the unit and tell the user which note it came from so they
can rotate it. Never "redact" it in place and ship the line.

## 8. Serving

```
Content-Type: text/markdown; charset=utf-8
Link: <llms.txt>; rel="describedby"
X-Markdown-Tokens: <n>
```

and on the HTML page a twin points at:

```
Link: <page.md>; rel="alternate"; type="text/markdown"
```

Private artifacts add `Cache-Control: private, no-store`. All of this is `/ldo` P13 over a
live HTTP request, not something `llms_lint.py` can check.
