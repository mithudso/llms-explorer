The llmsx logo: a tree mark and a monoline wordmark, drawn as SVG paths with no font dependency.

| File | Use | Ink |
|---|---|---|
| `llmsx-lockup.svg` | Header, documents, slides on light grounds | mark `accent` with white glyph; wordmark `ink` |
| `llmsx-lockup-reversed.svg` | Same, on `ink` or other dark grounds | mark `paper` with `ink` glyph; wordmark `paper` |
| `llmsx-mark.svg` | Square spaces: app icon, avatar, social card corner | `accent` square, white glyph |
| `llmsx-mark-reversed.svg` | Square spaces on dark grounds | `paper` square, `ink` glyph |
| `llmsx-favicon.svg` | Browser tab and anything at 32px or below | `accent` square, white glyph, heavier strokes |
| `llmsx-glyph-ink.svg` | Single-colour use: stamps, embossing, monochrome print | `ink` only, transparent ground |
| `llmsx-wordmark.svg` | Wordmark alone where the mark already appears nearby | `ink` |
| `llmsx-wordmark-reversed.svg` | Wordmark alone on dark grounds | `paper` |
| `llmsx-mark-3072.png` | Raster mark where SVG is not accepted and a file under 150 KB is required (3072 x 3072, 124 KB, transparent corners) | as `llmsx-mark.svg` |
| `llmsx-mark-1024.png` | Raster mark for app stores, avatars, social profiles (1024 x 1024, 33 KB) | as `llmsx-mark.svg` |

The glyph is the concept tree: a root node, a stem, a filled node for a published reference and a ring for a frontier name. Keep clear space of a quarter of the mark's width on every side. The mark's corner radius is 12 on a 64 grid (18.75% of its width); keep that ratio when you redraw it at other sizes.
