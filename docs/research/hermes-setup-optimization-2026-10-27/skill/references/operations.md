# Installed setup contract

Version: 1.0.0
Delta: initial two-host operations guidance.

The selected stack is native curated memory plus session history, shared Stele project memory, local keyword/source retrieval and Context7 documentation. External automatic memory providers are off. Their existing stored data and credentials remain available for a separately verified migration.

The built-in compressor uses lean tail retention and preserves recovery through session history. MCP tools use progressive schema disclosure with a 1,200-token catalog listing cap. The Hub allowlist contains only keyword lookup, concept lookup and concept-pack reading; it cannot start embeddings or indexing through that surface.

Hermes package management owns its Python environments and native tools. Read the installation facts rather than guessing an interpreter path. Do not run raw pip or uv inside a managed environment. Preserve an unfinished update's owner; read commands can trigger pending completion in the published launcher.

Use the native `terminal` tool to run the published Hermes command with `memory status`, `mcp list` or `mcp test <name>` after checking update state. Use the configured CLI for functional acceptance, with a bounded turn count and a dedicated temporary working directory. Keep ordinary user sessions intact.

Do not force the model's advertised native window into configuration. Query the managed router without autoloading first and bind the actual launch context. A short answer is a smoke test; tool execution and memory recovery need their own checks.

The Mac and Linux machine have separate native profile files. Shared Stele records cross that boundary when the correct project is selected. Do not synchronize live SQLite databases or point two independent agents at the same native memory directory.
