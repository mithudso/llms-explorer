## YoCAD™ Modeling


**YoCAD™ Modeling** is Yo.Town 3D Maker's **AI-powered 3D modeling** feature. You can generate and iterate editable 3D models in the browser through natural language, code editing, or both. It is suited for fast concept validation, printable objects, and pre-production shape exploration. The underlying parametric CAD engine uses the OpenSCAD stack, while the user-facing product and UI are unified as **YoCAD™**.

## Features

- **⓵ AI Agent**: describe the 3D result you want, as in a chat  
- **⓶ Parameters**: drive the model through parameters for different outcomes  
- **⓷ Code Editor**: view and edit the script the tool generated for you  
- **⓸ Example prompts**: pick a ready-made line to try the flow once  
- **⓹ Recent conversations**: past turns stay here—handy when you keep working on the same thing  
- **⓺ Content**: type at the bottom in plain language what you want to make or change  

**Chinese or English** both work—describe what you want the way you'd tell a friend. In **⓺ Content**, say **what you want and roughly how big**; you don't need technical terms. The tool turns that into runnable script behind the scenes. The generated script appears in the **⓷ Code Editor**; to change numbers or structure, click **⓶ Parameters** in the top bar.

### Parameters

- After the model is generated, click **⓵ Parameters**, adjust values in the panel, and preview different results in real time.

### Code mode (Code Editor)

After switching to the **⓸ Code Editor**, you're in **code mode**: **parametric modeling** with a YoCAD™-style script—code on the left, geometry on the right.

- **Top bar**  
  - **⓵ Import**: import an existing YoCAD™ script  
  - **⓶ Export**: export the current code as a YoCAD™ file  
  - **⓷ Run**: After modifying the code, click **Run** to see the updated model.

## Suggested flow (from first use to export)

**Path A: start from chat (beginners)**

1. Open the **AI Agent** and click an **example prompt** to run through the whole flow.  
2. Start with **one sentence** in the input area; if the result is off, **add more detail** (size, purpose, what to change).  
3. The tool **auto-generates** YoCAD™-style code and **runs it automatically** after generation; the model refreshes on the right.  
4. If you're happy with the result, click **⓶ Parameter adjustments**, tune values in the panel, and preview different outcomes in real time.  
5. If it's still not right, switch to the **⓷ Code Editor (code mode)**, edit **variables and parameters** in the code, then click **Run** manually to see the updated model.  

**Path B: start from code (if you already know scripting)**

1. Go straight to the **⓸ Code Editor**, **import** a script, or start from blank.  
2. Use variables and comments to keep parameters clear; click **Run** to check the geometry on the right.  

:::warning
Generation may occasionally fail; that is normal. Try a different prompt, or edit the code manually.
:::

## FAQ

### Q: What if the result doesn't match what I imagined?

A: Add **constraints** (size, proportions, wall thickness, hollow or solid, etc.) or **describe it in steps** (main body first, then details).

### Q: Do I have to know YoCAD™?

A: **No**. You can rely entirely on natural language at first; open the code editor when you need it.

## Real Crafting


Real Crafting is Yo.Town Maker's professional 3D sculpting and modeling tool. It offers powerful carving features and rich auxiliary tools so you can freely add bases, cutouts, split hinges, decorations, and more to existing 3D models.

## Features

- **⓵ Joint**: Quickly create mortise-and-hinge connections for easier assembly
- **⓶ Carve**: Shape surface details like clay carving
- **⓷ Add-on**: Attach extra parts to the model to build a more suitable form
- **⓸ Base**: Add a base or display stand to improve placement and presentation

## Control Panel

The control panel is at the bottom with three main tabs: **Carve**, **Add-on**, and **Base**.

### Joint

- **⓵ Operate**: Use locate, translate, rotate, and hide to position the cutting tool on the model
- **⓶ Cutting Tool**: Choose different joint types to quickly create connection structures

:::tip Tip
Click **Import My Tool** to upload a custom model and use it as a cutting tool.
:::

- **⓷ Adjust Tool Size**: Scale the tool to control joint size and fit
- **⓸ Pro Settings**: Fine-tune parameters to precisely control tool size, depth, and more
- **⓹ Confirm**: Click confirm to apply the result

### Carve

- **⓵ Operate**: Use locate, translate, rotate, and hide to position the carving tool on the model
- **⓶ Carving Tool**: Choose different carving tools to cut into the model, and adjust the tool as needed

:::tip Tip
Click **Import My Tool** to upload a custom model and use it as a carving tool.
:::

- **⓷ Adjust Tool Size**: Adjust the size of the sculpting tool to change the carving range
- **⓸ Confirm**: After sculpting is complete, click confirm to apply effects

:::warning Text size adjustment
The footprint of a full text line is controlled by **Size**, not post-creation **Width**. Set **Size** before you click **Create 3D Text**.
If text is already created, adjust **Size** again, then click **Create 3D Text** to regenerate.
:::

### Add-on

- **⓵ Operate**: Use locate, translate, rotate, and hide to position add-on objects on the model
- **⓶ Add-on objects**: Attach elements to the model and combine them into more complex forms

:::tip Tip
Click **Import My Tool** to upload a custom model and use it as an add-on object.
:::

- **⓷ Adjust Tool Size**: Adjust the size of add-on tools to change the attachment range
- **⓸ Confirm Attachment**: Click confirm to complete attachment

### Base

- **⓵ Operate**: Use locate, translate, rotate, and hide to position base objects on the model
- **⓶ Base objects**: Choose a base type (base or platform) and add it to the model

:::tip Tip
Click **Import My Tool** to upload a custom model and use it as a base object.
:::

- **⓷ Adjust Tool Size**: Adjust the size of base tools to change the base range
- **⓸ Confirm Creation**: After adjusting parameters, click confirm to create the base

:::warning Positioning tip
After selecting a tool in Real Crafting, click directly on the model surface to **locate** it. The tool snaps to that surface for faster placement.

If you do not want snap behavior, switch to **Translate**, **Rotate**, or **Hide** in the **Operate** area, then fine-tune position and orientation manually.
:::

## FAQ

### Q: What should I do if the model is deformed during sculpting?

A: Adjust carving depth and use smaller depth values for gradual carving. If deformation is severe, use undo to restore.

### Q: How to precisely control object position?

A: In the **Operate** area, use **Locate**, **Translate**, and **Rotate** to adjust the position and orientation of tools, add-on objects, or bases before you confirm.

### Q: Can I use multiple auxiliary tools simultaneously?

A: Yes, but only one tool can be active at a time. You can quickly switch tools and use them in combination.

### Q: Can the base size be adjusted?

A: Yes. Before you click **Confirm Creation**, use the **Radius** and **Depth** sliders in the base panel to adjust the base tool range.

### Q: Can attached add-on objects be edited separately?

A: No. After you click **Confirm Attachment**, add-on objects merge into the target model and can no longer be selected or edited separately. Finish positioning and orientation with locate, translate, and rotate before you attach.

### Q: How do I delete model blocks?

A: In the **Operate** area, use **Hide** to remove model blocks.

## Playground


Playground is Yo.Town's interactive 3D modeling workspace, providing complete 3D model creation, editing, and management features. Here, you can freely create and edit models, and experience various 3D tools.

## Features

- ⓵ **Text**: Add text and set text size, thickness, font and other properties.
- ⓶ **Geometry**: Add various shapes such as cubes, spheres, cylinders, etc.

## Control Panel

The control panel is located at the bottom. The first item is a dropdown selector that displays different content based on the selected dropdown title.

### Help Tools

- ⓵ **Help**: Show/hide the help panel with feature descriptions and guides
- ⓶ **Measure Mode**: Measure distances, edges, and model dimensions
- ⓷ **Magnetic Mode**: When enabled, moving objects snaps them to other objects or the grid for precise alignment
- ⓸ **Group**: Group multiple selected objects as one for unified transform
- ⓹ **Ungroup**: Split a grouped object back into independent parts
- ⓺ **Remove**: Delete the selected object
- ⓻ **Union**: Boolean union, merge overlapping bodies into a new one
- ⓼ **Subtract**: Boolean difference, subtract later objects from the first
- ⓽ **Intersect**: Boolean intersection, keep only the overlapping region
- ⓾ **Move**: Enable translate gizmo to move along axes/planes
- ⑪ **Rotate**: Enable rotate gizmo to rotate around axes
- ⑫ **Scale**: Enable scale gizmo to change object size
- ⑬ **Gizmo**: Free rotation 3D scene viewing angle, viewing model each angle

### Text Tool

When "Text" is selected, it displays:
- ⓵ **Size**: Adjust text size (default 36)
- ⓶ **Thickness**: Adjust text thickness (default 10)
- ⓷ **Font**: Select font (Running Script, Regular Script, Song Typeface, Bold, etc.), click "Custom Font" to upload custom fonts
- ⓸ **Content**: Enter the text to create
- ⓹ **Create 3D Text**: Click button to generate 3D text model

### Geometry Tool

When "Geometry" is selected, it displays:
- ⓵ Hover a geometry icon to see its label
- ⓶ Click a geometry icon to create the corresponding shape in the 3D view

## FAQ

### Q: How to precisely align models?

A: Enable **Magnetic Mode**. When moving models, they snap to another model for precise alignment and connection.

### Q: Can I edit multiple models simultaneously?

A: Yes, first select multiple models (using multi-select), then use the group function to combine them, and you can edit them together.

### Q: What file formats are supported?

A: Supports importing .glb, .3mf, .stl, .obj, .ply, .fbx formats

### Q: How to undo operations?

A: Use the undo button (↶) in the top toolbar to undo the previous operation.

## Repair


The Repair Model helps you fix various defects in 3D models, including holes, breaks, non-manifold edges, and other issues. This tool provides two modes: quick repair and deep repair, to meet different scenario needs.

## Features

- **⓵ Correction**: When you're unsure where problems exist, click this to let the system scan your model
- **⓶ Eraser Tool**: Remove unwanted small pieces, supports, or noise points like using an eraser
- **⓷ Mesh Reconstruction**: When the model mesh is too messy, or you want the model to be more suitable for printing or rendering, this one-click feature reorganizes the mesh

## Control Panel

The control panel is located at the bottom and contains three main tools: Correction, Erase, and Rebuild Mesh.

### Correction

- **⓵ Quick Repair (Common Issues)**: AI detects and fixes common issues
- **⓶ Deep Repair (&lt;50MB, Slower)**: Processing time depends on the model
- **⓷ Defect Detection**: Click this first to check if the model has any problems
- **⓸ Automatic Repair Model**: After selecting the mode, click this and the system will automatically repair your model

:::warning Note
If the model is too complex or the file is too large, repair may fail.
:::

### Erase

- **⓵ No Erase**: Turn off the erase function
- **⓶ Radius**: Like using an eraser, adjust the radius size to erase unwanted parts on the model
- **⓷ Frustum Selector**: Select the area to delete from the current view
- **⓸ Region Selector (Requires Segmentation)**: Requires model segmentation first, then select specific regions to delete
- **⓹ Confirm All Deletion**: After selecting the parts to delete, click this button to confirm and smoothly delete the selected area.

### Rebuild Mesh

- **⓵ Rebuild Ratio**: Drag the slider to adjust (default 0.8). Higher values optimize more thoroughly but may lose details
- **⓶ Start Rebuilding Mesh**: After adjusting the ratio, click this and the system will reorganize the model mesh

:::warning Note
Rebuilding mesh will lose model colors. Save the model first.
:::

## FAQ

### Q: What should I do if the model is deformed after repair?

A: You can try reducing the rebuild ratio or using quick repair mode. If the problem is serious, it's recommended to use the eraser tool to manually clean up before repairing again.

### Q: How long does deep repair take?

A: Processing time depends on model complexity and file size.

### Q: Can I undo repair operations?

A: You can use the undo button (↶) in the top toolbar to undo the previous operation.

### Q: What file formats are supported?

A: Supports importing .glb, .3mf, .stl, .obj, .ply, .fbx formats

## AI Segmentation


AI Segmentation helps you quickly and accurately segment 3D models into multiple parts. It combines quick, deep, and manual controls so you can choose the right workflow for each model.

## Features

- **⓵ Quick Segmentation**: AI automatically identifies and segments the model for most scenarios
- **⓶ Deep Segmentation**: Finer control with adjustable depth level
- **⓷ Manual mode**: Full manual control—select regions, smart lasso, brush selection, merge regions
- **⓸ Mode selector**: Click to pick the segmentation preset or level

## Control Panel

The control panel is located at the bottom and contains three main modes: Quick Segmentation, Deep Segmentation, and Manual Mode.

### Quick Segmentation

- **⓵ Coarse**: Fast processing with larger regions—good for simple models or quick previews
- **⓶ Moderate**: Balanced speed and precision—good for most models (recommended)
- **⓷ Fine**: Higher precision and more detail—good for complex models
- **⓸ Start Quick Segmentation**: After choosing a precision level, click here and let AI segment the model

### Deep Segmentation

- **⓵ Depth level**: Drag the slider (default 50). Higher values yield finer segmentation
- **⓶ Start Deep Segmentation**: After adjusting parameters, click here to run

### Manual Mode

<!--  -->

**Select Region**
Click to select regions. You can smooth contours and cut out regions (basic splice / mushroom splice / fine / chain splice).
  - **⓵ Contour Thickness**: Drag the slider to adjust stroke width
  - **⓶ Dot Size**: Drag the slider to adjust Dot Size

**Smart Lasso**
  - **⓵ New cut**: Click to create a new cut region
  - **⓶ Close contour**: Close the contour to create a new cut region

**Brush Selection**
  - **⓵ Brush Level**: Drag the slider to adjust brush size
  - **⓶ Extract color**: Sample different colored regions

**Merge Regions**
  - **⓵ Merge regions**: Select a model block, click **Merge Regions**, then click other blocks to merge them into one

:::warning Recommendation
When splitting parts, start with **Fine** segmentation, merge the parts you need, then continue with the lasso; lasso-based segmentation usually avoids pits or uneven surfaces.
:::

## FAQ

### Q: What should I do if the model is deformed after segmentation?

A: Segmentation operations do not change model shape. If deformation occurs, it may be a display issue. Try refreshing the view or reloading the model.

### Q: Can I undo segmentation operations?

A: Yes. Click the **Undo** button (↶) in the top toolbar to revert segmentation and restore the model to its pre-segmentation state.

### Q: Can segmented regions be edited separately?

A: Yes. After segmentation, each region becomes an independent **Model Block**. You can move, rotate, and scale blocks on this page. For further work such as carving, repair, or recoloring, continue in the corresponding pages like Real Crafting or Repair Model.

### Q: What file formats are supported?

A: Supports importing .glb, .3mf, .stl, .obj, .ply, .fbx formats

### Q: How long does segmentation take?

A: Processing time depends on model complexity and the selected mode.

<details>
<summary>Q: What should I do if sharp edges appear during segmentation?</summary>

A: Try adjusting the **smooth contour** between adjacent regions so edges blend more naturally.

:::warning Note
Do not adjust smooth contour while **segmenting adjacent regions**, or you may get sharp edges or boundary artifacts.
:::

</details>

<details>
<summary>Q: What should I do if many small regions appear during segmentation?</summary>

A: If many small regions appear after segmentation, try:

1. **Undo first**: Click undo to go back to before segmentation
2. **Adjust smoothness**: Tune smoothness between adjacent regions repeatedly until it looks right
3. **Repair first**: If it is severe, use [Repair Model](/docs/core/repair), then segment again

</details>

<details>
<summary>Q: Any tips for segmenting a model into parts?</summary>

**A:** Patterns that often help (no single “right” order—pick what fits the model):

1. **Order of cuts**
   - **Small first (optional)**: Handle **small protrusions or attachments** first, then segment the main body.
   - **Large first (optional)**: Define **major blocks** from assembly and print orientation, then refine each block.

2. **Semi-enclosed parts** (shells, covers, half-wraps, etc.)
   - Decide **which side is easier to keep intact**—clips and alignment often sit on one side; try to **disturb that side less** when segmenting.
   - Start by separating a **more independent region**; if the boundary is messy, regions fragment, or clips suffer, **undo**.
   - After undo, **reselect from an adjacent large region** and segment again—retrying beats forcing a bad cut.

For more detail, see **[AI Segmentation](/docs/core/segment)**.

</details>

<summary>Q: How do I upload a custom font?</summary>

**A:** The app supports your own fonts. Typical entry points:

- **Real Crafting**: **Carve** → **3D text**, then **Custom font** in the font list and upload

<details>
<summary>Q: My 3D text is in the wrong place—how do I adjust it?</summary>

**A:** In the **Playground** or **Real Crafting**, after creating text open **Manipulate** and use:

- **Place**: **Click** on the model surface—the text **snaps to that surface**
- **Move**: **Drag** the text to reposition
- **Rotate**: **Drag** to change orientation
- **Remove**: Delete the current 3D text

</details>

<details>
<summary>Q: Why doesn't changing “width” seem to do much?</summary>

**A:** Set **size** to a good range **before** you create 3D text. After creation, “width” usually adjusts **letter spacing (tracking)**, not the **overall footprint** of the whole line.

:::warning
The footprint of the full text line is controlled by **size**, not post-creation "width". Adjust **size** before creating 3D text. If text is already created, change **size** and click **Create 3D Text** again to regenerate.
:::

</details>

<details>
<summary>Q: Why does my browser show “This page is not responding”?</summary>

**A:** Common causes include:

- **Device resources are tight**: If your computer is modest or many apps/tabs are open, the browser has fewer resources and the page may freeze
- **The model is too complex**: Very high polygon counts, heavy detail, or multiple large models can increase processing time or trigger no-response states
- **Browser or drivers are outdated**: An old browser build, hardware acceleration issues, or outdated GPU drivers can make 3D rendering unstable
- **Browser environment interference**: Too many extensions (ad blockers, script tools, etc.) or corrupted cache can slow or stall the page
- **Network instability**: Connection drops or timeouts can make the page look stuck while loading

:::tip Suggestion
Close unnecessary background apps and tabs → reduce model complexity (or process in batches) → update browser and GPU drivers → disable suspicious extensions and clear cache, then retry.
:::

</details>

<details>
<summary>Q: How do I adjust segmentation fineness?</summary>

**A:** Open **[AI Segmentation](/docs/core/segment)** and use the bottom panel:

- **Quick Segmentation**: choose **Coarse / Moderate / Fine** (start with **Moderate**), then **Start Quick Segmentation**. Higher presets yield finer regions.
- **Deep Segmentation**: drag **Depth level** (default 50)—higher values mean finer cuts—then **Start Deep Segmentation**.

See [AI Segmentation](/docs/core/segment) for the full walkthrough.

</details>

<details>
<summary>Q: Does the app auto-save my model?</summary>

**A:** Two different things:

- **Editing progress**: Auto-saved in each workspace (about every 10 seconds). You can continue when you return to the same tool.
- **Model files**: Not auto-downloaded. Use top-bar **Export** or **Share / save** to keep a file (see “How do I save the model after editing?” above).

:::warning Note
If you see “This site can’t be reached,” try clearing **browser cache** and refreshing. Refresh may **discard unsaved progress** that was not saved to your space—export or save important work first.
:::

</details>

<details>
<summary>Q: Why can't I take the model on this page to another tool?</summary>

**A:** If you switch via the **left navigation** or by opening a new URL, the **current model does not follow**—that is expected. To move the model you are editing to another workspace, use the round buttons at the bottom-right:

- **Purple Workflow**: switch to Playground, Repair Model, AI Segmentation, Real Crafting, etc., and **carry the current model** (see [Common Features](/docs/features/common-features)).
- **Gray Help (?)**: view guides and **jump to other feature pages** (also carries the current model).

If the work is already saved, use **Open Model** on a row in **[Artifacts Posts](/docs/features/posts)** and pick the target tool.

</details>

<details>
<summary>Q: Boolean ops in Playground did nothing—what should I check?</summary>

**A:** Try this order:

1. **Two objects selected** (multi-select) with real **overlap**
2. For **Difference**, order matters: **base first, cutter second** (result is base − cutter)
3. Wait a few seconds for processing; if still nothing, **undo**, adjust overlap, and retry

See **[Boolean Operations](/docs/workflow/boolean-operations)** for examples.

</details>

<details>
<summary>Q: How do I export a model file to my computer?</summary>

**A:**

- In any workspace, click top-bar **Export**, choose **GLB / 3MF / STL**, etc. The file downloads to your browser’s default downloads folder
- For more variants, open **[Convert Model](/docs/features/convert)** (e.g. compressed vs raw GLB) and click **Run**

:::tip Choosing a format
- Share online, smaller file → **Compressed GLB**
- Color 3D printing → **3MF**
- Maximum printer compatibility → **STL** (no color data)
:::

</details>

## Convert Model


Convert Model lets you export your 3D model in different formats for 3D printing, sharing, or other workflows.

## Use Cases
When do you need Convert Model?

- **3D Printing**: You need to export the model in a printing format
- **Sharing Works**: You need to export into a format suitable for online display
- **Import into Other Software**: You need to convert into formats supported by other software

## How to Use
### Export Model

**Operation Steps:**
- ⓵ **Select Format Options**: In the bottom control panel, select the specific format variant (for example, Compressed GLB, Raw GLB, 3MF, or STL)
- ⓶ **Click Run**: After confirming, click the **"Run"** button. The file will download automatically.

## Supported Formats
### GLB Format
Suitable for online display, game development, and sharing.

**Format Options:**
- **Compressed GLB** (Recommended): Smaller file size, loads faster, suitable for most needs
- **Raw GLB**: Not compressed, larger file size, suitable for scenes that need further editing

**Features:**
- Supports colors and textures
- Supported by modern browsers
- Small file size, loads fast

### 3MF Format
Designed specifically for 3D printing and suitable for color printing scenarios.

**Features:**
- Supports colors and materials
- Supported by modern slicing software (e.g., BambuStudio, OrcaSlicer)
- Includes complete printing information

### STL Format
The most universal 3D printing format with the best compatibility.

**Features:**
- Supported by almost all 3D software and printers
- Simple file structure

## How to Choose a Format

- **Online display or sharing**: choose **Compressed GLB** (small file, supports color)
- **Color 3D printing**: choose **3MF** (supports color printing)
- **Standard 3D printing**: choose **STL** (no color data)
- **Import into other software for editing**: choose **Raw GLB** or **3MF** (keeps more information)

## FAQ
### Q: Where is the file after export?
A: The file will automatically download to the browser's default downloads folder. You can check it in the browser's download history.

### Q: Can multiple formats be exported at once?
A: One export supports only a single format. If you need multiple formats, export them separately.

### Q: How long does export take?
A: It depends on model complexity; usually from a few seconds to a few minutes.

### Q: Can the exported file be imported into other software?
A: Yes. The exported files are standard formats:
- **GLB**: Blender, Maya, Unity, Unreal, etc.
- **3MF**: BambuStudio, OrcaSlicer, Cura, PrusaSlicer, Windows 3D Builder, etc.
- **STL**: Supported by almost all 3D software

### Q: Why doesn't STL support colors?
A: STL only contains the model's shape information and doesn't include color data. If you need colors, choose GLB or 3MF.

### Q: What is the difference between Compressed GLB and Raw GLB?
A: Compressed GLB files are smaller but have the same quality, suitable for most uses. Raw GLB files are larger and fit scenes that need further editing.

### Q: Which is better for 3D printing, 3MF or STL?
A:
- **3MF**: Supports colors and materials; suitable for color printing and modern printers
- **STL**: If you need maximum compatibility, choose STL

If your printer supports 3MF and you need colors, choose 3MF; if you need maximum compatibility, choose STL.

## Style Transform


The Style Transform feature allows you to convert 3D models into different artistic styles and add unique visual effects. Whether you want a cubified pixel style or Yo.Town's signature style, it can be done easily.

## Feature Overview

### Cubification

- ⓵ **Blocky** - In the bottom control panel, choose **Blocky**
- ⓶ **YT Style** - In the bottom control panel, choose **YT Style** (coming soon)
- ⓷ **Voxel Level** - Drag the slider to set detail (range 1–10, default 5)
   - Low (1–3): larger blocks, good for quick previews
   - Medium (4–6): balances detail and performance (recommended)
   - High (7–10): more detail but longer processing (level 10 is very slow and not recommended for routine use)

## FAQ

### Q: Does Blocky change the model shape?

A: It changes the surface to a blocky look while trying to keep the overall shape and proportions of the original.

### Q: Can I undo a style conversion?

A: Yes. Use the undo button (↶) in the top toolbar to revert the conversion and restore the original model.

### Q: Is a higher Voxel Level always better?

A: Not necessarily. Pick a high level when you need fine detail, a low level for speed, and a medium level for balance (recommended).

### Q: How long does Blocky take?

A: It depends on model complexity and Voxel Level.

## Boolean Operations


This page focuses on practical Yo.Town Maker boolean operations: Union, Difference for hole-cutting, and Intersection extraction. You can run these in **either Playground or Real Crafting**, with different levels of flexibility and setup speed.

## When to use this

- Combine two models into one (Union)
- Cut holes or remove parts from a model (Difference)
- Keep only overlapping geometry (Intersection)

## Which approach to choose (focus on Difference)

### Option 1: Use Difference in Playground (more customizable)

**Pros**
- You can import custom models (including models generated from images), so flexibility is high.
- Better for personalized shapes and more complex cut paths.

**Watch-outs**
- You need finer manual control of position, size, and angle.
- New users may need a few tries to get alignment and overlap right.

:::warning
For Difference in Playground, selection order matters: select **A** first, then **B**.  
The result is **A - B**.
:::

### Option 2: Use Real Crafting (easier to start)

**Pros**
- More fixed and intuitive workflow, so it is quicker to learn.
- Basic position and size adjustments are often enough to get usable results.

**Watch-outs**
- Editable range is smaller than Playground, but faster for practical outcomes.
- This path is mainly based on platform-provided models and tools.

## Before you start

1. Open **Playground** and import or create 2 overlapping models (for example, a cube and a cylinder).
2. Position them so they clearly intersect.
3. Choose the boolean type you need: Union / Difference / Intersection.

:::tip
Before running boolean operations, create a backup copy (for example by sharing/saving as a post). If the result is not ideal, you can reopen that model and continue from there.
:::

## Example A: Union (merge into one object)

**Goal**: Merge a cube and a cylinder into one connected model.

1. Select both models (multi-select).
2. Click **Union** in the bottom help tools.
3. Check the result: they should become one object.
4. Use move/rotate/scale if you need to adjust placement.

**Quick checks**
- Is it still two separate objects?
- Is the merged seam acceptable?

## Example B: Difference (cut a hole)

**Goal**: Cut a cylindrical hole through a cube.

1. Prepare a base object (cube) and a cutter object (cylinder).
2. Select the base first, then the cutter.
3. Click **Difference**.
4. Check the result: the cube should have a hole or slot where the cutter overlaps.

**Quick checks**
- Selection order correct? (Wrong order can invert the result.)
- Does the cutter actually pass through the base?

## Example C: Intersection (keep overlap only)

**Goal**: Keep only the overlapping volume of a cube and a sphere.

1. Prepare two overlapping objects.
2. Select both objects.
3. Click **Intersection**.
4. Check the result: only the shared overlap remains.

**Quick checks**
- Is there enough overlap area?
- Does the shape match your expectation?

## Real Crafting quick tips

In Real Crafting, start with position and size tools for the fastest results:

1. Use **Locate** / **Translate** to place models with clear overlap.
2. Use **resize** controls to set hole diameter, thickness, or overlap volume after boolean ops.
3. Use **Rotate** when you need a different cut angle.
4. Export when satisfied; use carve, add-on, and base tools for finer surface work.
5. **Joint** tools support multiple mortise-and-hinge types for faster part connections.

## FAQ

### Q1: Nothing changed after clicking a boolean operation in Playground
- Make sure two objects are selected.
- Check that the two objects actually overlap.
- Processing may take a moment—wait and check again.

### Q2: Difference result looks reversed
- Re-run with correct selection order: base first, cutter second.

### Q3: Edges look rough after boolean
- Undo, slightly adjust overlap position, and run again.

## Disassembly workflow


This page describes a Yo.Town Maker workflow for 3D print part separation: model prep, repair, segmentation, and export—for everyday disassembly, structure tweaks, and pre-print cleanup.

## Detailed Steps for Model Disassembly

### Preparation Stage

```mermaid
flowchart LR
    A[Import file] --> B[Repair model]
    B --> C{Has defects?}
    C -->|Yes| D[Auto repair]
    C -->|No| E[AI segmentation]
    D --> E
    E --> F[Start segmentation]
```

### Manual Operation Stage

```mermaid
flowchart LR
    A[Manual mode] --> B{Good position?}
    B -->|Yes| C[Smooth boundary & choose connectormove out part]
    B -->|No| D[Smart lasso: new cut & close boundaryselect region: smooth & detach part]
    C --> E[Disassembly complete]
    D --> E
```

### Create or Prepare a Model

**Option A: Generate with AI**
- Use any model generation tool you prefer.

**Option B: Use your own model**
- Use an existing 3D model file.
- Or pick one from the model library.

### Import Model

**Recommended: Drag and drop**
- Drag the model file anywhere on the page.
- The system detects and loads it automatically.

**Alternative: Click Import**
- Click the top toolbar **Import** button.
- Select a file to finish import.

**Supported formats**: .glb, .3mf, .stl, .obj, .ply, .fbx

### Repair Model (Recommended)

**When should you repair first?**
- You get many tiny segmented regions.
- The model has defects or a complex structure.

### Segment Model

**Step Flowchart:**
```mermaid
flowchart LR
  A[Choose segmentation modeQuick / Deep / Manual] --> B[Run segmentationRegions shown in different colors]
  B --> C[Smooth regions]
  C --> D[Select regionClick Detach Region]
  D --> E[Choose splice typeRight-angle / Mushroom / Chain]
  E --> F[Small particles appearUndo]
  F --> G[Merge regionsClick Merge Regions]
```

:::tip Tip
If detached regions show small grainy artifacts, undo the step, then smooth the two adjacent regions several times.
:::

### Export Model

**How to export:**
```mermaid
flowchart LR
  A[Click Export] --> B[Choose output format]
  B --> C[Finish export]
```

:::warning Important
- For multi-part printing in slicer software, detach regions and move the parts apart before export.
:::
