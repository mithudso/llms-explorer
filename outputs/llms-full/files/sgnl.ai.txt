## What is Continuous Identity?

Continuous Identity represents the generational shift from traditional, static identity management to dynamic, event-driven identity security. Unlike conventional IAM approaches that rely on periodic access reviews and static entitlements, Continuous Identity enables organizations to:

- **Eliminate Standing Privileges**: No user or system maintains permanent access to critical resources
- **Make Real-Time Access Decisions**: Every access request is evaluated dynamically based on current context
- **Respond to Changing Conditions**: Access is automatically adjusted or revoked when risk conditions change
- **Implement Event-Driven Architecture**: Systems communicate through standards like CAEP and Shared Signals Framework
- **Achieve True Zero Standing Privilege**: Access exists only when needed, for as long as needed

SGNL is the definitive platform for implementing Continuous Identity, providing the technology foundation, policy engine, and integrations necessary to transform traditional IAM into a dynamic, responsive security architecture.

## Core Concepts

### Zero Standing Privilege (ZSP)

Zero Standing Privilege is SGNL's foundational approach to security that eliminates permanent access rights, dramatically reducing attack surface and minimizing the impact of credential theft. Unlike traditional least privilege approaches that still maintain standing access, ZSP ensures:

- Access rights exist only when actively needed
- Access is automatically revoked when conditions change
- No persistent privileges for attackers to target
- Dramatic reduction in blast radius from compromised credentials

### Context-Based Access Control

SGNL evaluates access requests based on rich contextual information, including:

- User attributes (role, department, location, employment status)
- Resource sensitivity and classification
- Time and duration of access requests
- Business justification and workflow status (active tickets, approvals)
- Security posture and risk signals from EDR/XDR systems
- Device compliance and management status
- Behavioral patterns and anomaly detection

### Just-in-Time Access

SGNL enables just-in-time access provisioning that:

- Grants privileges only when actively needed
- Automatically expires access after a defined period
- Requires re-authorization for continued access
- Maintains detailed audit logs of all access grants and usage
- Eliminates the concept of "permanent" access to critical systems

### Continuous Access Evaluation Protocol (CAEP)

SGNL implements and helped develop the CAEP standard to:

- Continuously evaluate session security throughout user sessions
- Automatically revoke access when risk signals are detected
- Respond to security events in real-time across all connected systems
- Share security signals across the enterprise ecosystem
- Enable coordinated response to security incidents
