# SpacePrompts

> AI prompt manager for organizing, enhancing, and reusing prompts across ChatGPT, Claude, Midjourney, and other AI tools.

## About

SpacePrompts is a prompt management platform that solves a common problem for AI power users: prompts get lost in ChatGPT history, scattered across Google Docs, Notion, and sticky notes, or simply forgotten after hours of refinement. The platform provides a single searchable library where users can save, tag, categorize, and version their prompts.

Key differentiators:
- **AI Enhancement**: One-click prompt improvement that makes prompts more specific and effective
- **Version control**: Full history of prompt changes with rollback capability
- **Cross-platform execution**: Run any saved prompt in ChatGPT, Claude, Gemini, or any AI tool with one click
- **Chrome extension**: Access your full prompt library as an overlay on any webpage
- **Templates**: Pre-built prompts for marketing, coding, writing, and more

SpacePrompts targets developers, content marketers, writers, researchers, and anyone who uses AI tools as part of their regular workflow. The free tier supports up to 50 prompts with core features; the Pro tier is unlimited.

## Developer API

SpacePrompts provides a REST API for programmatic access to prompts. Available on Pro and Team plans. All requests require an `X-API-Key` header. Base URL: `https://services.spaceprompts.com/api/v2`. Rate limited to 60 requests/minute per API key.

- [https://www.spaceprompts.com/api-docs](https://www.spaceprompts.com/api-docs): API Reference — full documentation covering authentication, base URL, rate limits, and all endpoints: GET /prompts/{slug} (retrieve a prompt by slug), POST /prompts/run/{slug} (run a prompt with a user query against the AI model), GET /token-count (count tokens for a given prompt and model — supports openai, claude, gemini, deepseek), and POST /prompts/enhance (AI-enhance a prompt, returns improved version). All endpoints support a `response_format=text` query parameter to return plain text instead of JSON.
