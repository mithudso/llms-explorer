# HostingPerTe

> IT: HostingPerTe è un provider italiano di servizi hosting attivo dal 2005. Offre soluzioni per privati, aziende e pubbliche amministrazioni, tra cui hosting condiviso, VPS, server dedicati, email professionale, PEC e servizi cloud.
> 
> EN: HostingPerTe is an Italian hosting provider active since 2005. It offers solutions for individuals, companies, and public administrations, including shared hosting, VPS, dedicated servers, professional email, PEC (certified email), and cloud services.

---

## Piani Hosting / Hosting Plans

IT:
- Hosting Linux: supporto PHP, MySQL, certificato SSL gratuito, con pannelli di controllo cPanel, Plesk e DirectAdmin.
- Hosting Windows: basato su Windows Server, compatibile con ASP.NET e MSSQL. Include pannello Plesk.
- Hosting WordPress: installazione rapida, backup automatici, protezione brute-force e caching server-side.
- Hosting Multidominio: consente la gestione di più domini da un solo account, ideale per agenzie.

EN:
- Linux Hosting: supports PHP, MySQL, free SSL certificate, with control panels such as cPanel, Plesk, and DirectAdmin.
- Windows Hosting: based on Windows Server, compatible with ASP.NET and MSSQL. Includes Plesk.
- WordPress Hosting: fast setup, automatic backups, brute-force protection, and server-side caching.
- Multidomain Hosting: manage multiple domains under one account, ideal for agencies.

## Server VPS

IT:
- VPS Linux: sistemi operativi CentOS, Debian, Ubuntu, Fedora, con accesso root completo, gestione via pannello opzionale.
- VPS Windows: Windows Server 2008/2012/2019, accesso RDP, installazioni personalizzate su richiesta.
- SSD e NVMe disponibili, snapshot, backup e upgrade dinamici.

EN:
- Linux VPS: OS options include CentOS, Debian, Ubuntu, Fedora, with full root access and optional control panel.
- Windows VPS: Windows Server 2008/2012/2019 with RDP access, custom installations on request.
- SSD and NVMe storage available, snapshots, backups, and dynamic upgrades supported.
