## Problems, failure modes and limitations

- [statement] New Relic directs applications to preload the Node agent with `node -r newrelic ./dist/server.js`; when startup flags cannot be controlled, place `require('newrelic')` first in the main module, before other packages. Late loading can prevent proper instrumentation. New Relic warns that the first-line fallback causes instrumentation issues with Babel or a similar transpiler. (medium confidence) (verified as of 2026-11-02) — https://docs.newrelic.com/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent/ · keywords: New Relic Node preload order and MongoDB trace-verification boundary · also: https://docs.newrelic.com/docs/apm/agents/nodejs-agent/troubleshooting/troubleshoot-your-nodejs-installation/
- [statement] For an ESM application that uses a configuration file, New Relic requires changing its extension from `.js` to `.cjs` because the CommonJS agent reads the file with `require()`; otherwise startup can fail with `ERR_REQUIRE_ESM`. (low confidence) (verified as of 2026-11-02) — https://docs.newrelic.com/docs/apm/agents/nodejs-agent/installation-configuration/es-modules/ · keywords: New Relic Node preload order and MongoDB trace-verification boundary · also: https://raw.githubusercontent.com/newrelic/docs-website/develop/src/content/docs/apm/agents/nodejs-agent/installation-configuration/es-modules.mdx
- [statement] New Relic documents that `newrelic.instrumentLoadedModule` is unsupported for ESM: ESM bindings cannot be assigned, preventing replacement of exports after loading. Do not plan an ESM verification procedure around retrofitting this API after imports. (low confidence) (verified as of 2026-11-02) — https://docs.newrelic.com/docs/apm/agents/nodejs-agent/installation-configuration/es-modules/ · keywords: New Relic Node preload order and MongoDB trace-verification boundary · also: https://raw.githubusercontent.com/newrelic/docs-website/develop/src/content/docs/apm/agents/nodejs-agent/installation-configuration/es-modules.mdx

## Facts and statements

- [statement] For ESM applications, New Relic requires the ESM loader together with the agent: `node --import newrelic/esm-loader.mjs -r newrelic ./dist/server.js`. Loading the agent alone does not fulfill this documented ESM bootstrap requirement. The ESM setup page labels this instrumentation experimental and warns that breaking changes can occur while its loader dependency is experimental. (medium confidence) (verified as of 2026-11-02) — https://docs.newrelic.com/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent/ · keywords: New Relic Node preload order and MongoDB trace-verification boundary · also: https://docs.newrelic.com/docs/apm/agents/nodejs-agent/installation-configuration/es-modules/, https://docs.newrelic.com/docs/apm/agents/nodejs-agent/troubleshooting/troubleshoot-your-nodejs-installation/, https://raw.githubusercontent.com/newrelic/docs-website/develop/src/content/docs/apm/agents/nodejs-agent/installation-configuration/es-modules.mdx
- [statement] The pinned Node release 22.14.0 CLI documents that modules preloaded with --require run before modules preloaded with --import. Repeated import preloads execute sequentially in order, beginning with those supplied in NODE_OPTIONS. The option order shown in New Relic examples does not reverse that runtime ordering. (medium confidence) — https://nodejs.org/download/release/v22.14.0/docs/api/cli.html · keywords: New Relic Node preload order and MongoDB trace-verification boundary · also: https://docs.newrelic.com/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent/, https://raw.githubusercontent.com/nodejs/node/v22.14.0/doc/changelogs/CHANGELOG_V22.md
- [statement] New Relic instructs users to generate application traffic and wait a few minutes for APM data. Its troubleshooting guide warns that short-lived tests may exit before data is reported and that configuration, framework or Apdex settings can explain missing transaction traces. The default agent log is newrelic_agent.log in the application directory unless logging settings have changed. (medium confidence) (verified as of 2026-11-02) — https://docs.newrelic.com/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent/ · keywords: New Relic Node preload order and MongoDB trace-verification boundary · also: https://docs.newrelic.com/docs/apm/agents/nodejs-agent/troubleshooting/troubleshoot-your-nodejs-installation/
- [statement] In a separate ESM issue, rChaoz reported an empty database tab despite manually created `newrelic.startSegment()` segments. A maintainer explained that recording database segments and attributes requires appropriate shim methods. The reporter later named SvelteKit and Prisma. This attributed exchange illustrates the distinction between custom segments and database telemetry; it does not establish MongoDB or Mongoose version support.
