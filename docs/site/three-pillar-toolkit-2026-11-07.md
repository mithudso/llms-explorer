## What visitors can do

The front door names convergence skills, terminal workbenches and agent context libraries. Guides and empirical reports support those three jobs. The Concept tree stays explicit and the broad library remains intact. /toolkit/ explains all six offering categories and their requirements. The hosted interfaces remain separate from local/public tools; this change does not qualify backend availability.

Each of the31skill pages has an exact-directory install command, full source prompt, illustrative Before/After/Changes controls, source prompt-size estimate and a local usage-cost calculator. The calculator uses exact fixed-point decimal arithmetic and user-supplied billable counts/rates. It does not send or store the values. Cache-specific rates, tool fees, taxes and subscription accounting remain separate. No new optimizer run or gain is claimed.

Public context bundles package existing public facts into <slug>.llms directories with five family files, an explicitly limited one-node public graph and an integrity manifest. The short layer is a labeled opening extract. The vocabulary file explicitly says no independently curated vocabulary is supplied by this export. Source links and file hashes do not certify factual accuracy. No private research corpus, ledger or graph is exported.

LLMSX0.2.8 isolates the private shared renderer behind the optional corpus extra. Base/public context and TUI installs use public dependencies; advanced corpus/family generation retains an explicit authorized-renderer requirement. Developer tests retain that dependency. No private library code or repository visibility was changed.

LLMSX0.2.8 adds `llmsx context list` and `llmsx context get <slug>`. Downloads verify the catalog archive hash, exact ZIP member names, size limits and every member's declared hash/size before writing. Existing paths are refused. Read commands remain compatible with `llmsx concepts --data . show/serve`. No model or credentials are required. `llmsx tui` remains the tree browser; `llmsx explorer` remains the richer workbench. Published `ghx` and `github-explorer` are aliases; `skillsx` remains a separate app.

## Strict pip compatibility correction

The initial uv installation accepted an optional direct-URL requirement without the whitespace that PEP508 requires before its environment marker. Standard packaging.Requirement rejected that metadata. Release0.2.9 fixes the writer, validates every emitted requirement and uses normal pip for the final anonymous installation proof. This does not change the context data or the optional corpus-renderer boundary.
