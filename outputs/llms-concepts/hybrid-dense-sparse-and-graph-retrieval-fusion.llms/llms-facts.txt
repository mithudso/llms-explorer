# Hybrid Dense, Sparse, and Graph Retrieval Fusion — Facts
- Reciprocal Rank Fusion (RRF) with smoothing parameter k=60 achieves scale-invariant rank aggregation across unbounded BM25 lexical scores, dense vector cosine similarities, and graph traversal distance metrics without parameter tuning. — https://dl.acm.org/doi/10.1145/1571941.1572114
- Three-way hybrid fusion (sparse lexical BM25 + dense embedding + topological graph PPR) achieves higher Mean Reciprocal Rank (MRR@10) and NDCG@10 than any pairwise combination on heterogeneous technical corpora. — https://arxiv.org/abs/2404.16130
- Rank calibration via min-max normalization or z-score standardization before linear combination requires manual tuning per dataset distribution, whereas RRF provides distribution-free robustness across drifting corpus sizes. — https://dl.acm.org/doi/10.1145/1571941.1572114
