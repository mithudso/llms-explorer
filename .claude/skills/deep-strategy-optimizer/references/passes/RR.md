# RR — Return and risk metrics

Question this family answers: Is each metric computed by one correct convention?

16 passes. Each row is one pass: one evaluation method, one check, one fix. `Fails →` is the severity the finding carries when the check fails (see SKILL.md § Severity). Sources for every method are in `../evaluation-methods.md`.
