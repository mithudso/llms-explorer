  **Markup hazard:** `#docset-results` had to become `markup=True` for the file link, which would make Rich parse brackets in indexer JSON output. Every raw write now goes through `rich.Text` via `_docset_log()`; the backend is rendered `(chroma)` not `[chroma]` for the same reason.
