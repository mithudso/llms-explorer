# Citability.ai — Full Context

## About
Citability is a Domain Intelligence Platform that measures AI visibility, citation readiness, and agentic commerce readiness across 607M domains. We help businesses understand how AI systems discover, cite, and interact with their websites.

## Core Features
- AI Visibility Scanner: 3-pillar scoring (Discovery, Agentic, Citation) across 51 endpoints
- Citation Readiness V2: Evidence-based 5-pillar scoring (Authority, Performance, Content, Social, Agentic)
- Content Extractability Analysis: Paragraph structure, quotability, hierarchy clarity, front-loading, entity explicitness
- Domain Intelligence: WHOIS, DNS, CDN detection, tech stack analysis across 607M domains (Common Crawl)
- Competitive Intelligence: Keyword gaps, backlink analysis, authority comparison
- SEO Command Centre: 7-source automated analysis (GA4, GSC, DataForSEO, ADP, Citations, Technical SEO, Common Crawl)

## Technology
- Backend: Python 3.12, FastAPI, PydanticAI agents, DuckDB
- Frontend: Next.js 16, React 19, TypeScript, Tailwind CSS v4
- Infrastructure: DigitalOcean App Platform, Cloudflare, Supabase
- AI: 8 PydanticAI agents with model fallback chains (OpenRouter, OpenAI, Anthropic)

## API
- 152 endpoints across 24 route modules
- Authentication via Clerk (OAuth) or API key
- Rate limiting per tier

## Standards Supported
- ADP v2.1 (AI Discovery Protocol)
- IndexNow
- Schema.org JSON-LD
- robots.txt AI crawler directives
