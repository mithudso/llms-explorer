# MongoDB University & Certification Program

Expert reference for MongoDB's education platform (learn.mongodb.com), its four active Associate certifications, the free Skill Badges program, instructor-led training, and academic/partner enablement programs. Use this skill when advising customers, teams, or MongoDB TAMs on learning and credentialing paths.

All facts verified against official learn.mongodb.com pages as of 2026-06-16. Volatile details (exam question counts, upcoming beta exams) are stamped accordingly.

## Quick Reference: Certification Decision Table

| Role | Certification | Questions | Time | Price | Status (2026-06-16) |
|------|--------------|-----------|------|-------|---------------------|
| Application Developer | Associate Developer | 53 MCQ | 75 min | $150 | Active, GA |
| Data Modeler / Architect | Associate Data Modeler | 70 MCQ (60 scored, 10 unscored) | 105 min | $150 | Active, GA |
| Atlas Platform Admin | Associate Atlas Administrator | TBD | 120 min | $150 | Active, GA |
| Self-Managed DBA | Associate DBA | TBD | TBD | $150 | Revision in progress — beta sign-up open |

All exams: online proctored via ProctorU (switched from Examity April 2024), English, no prerequisites, pass/fail with domain score report, Credly badge upon passing.

## Certifications Detail

### Associate Developer ($150, 53 MCQ, 75 min)
- Languages: C#, Java, Node.js, Python, PHP — each variant is a separate $150 purchase
- Prep: language-specific Developer Learning Path (~20 hr each)
- Materials: Exam Study Guide, Practice Questions, Certification Deep Dive video

### Associate Data Modeler ($150, 70 MCQ, 105 min) — GA since March 18, 2024
- Validates: relational-to-document model migration, schema design patterns, anti-patterns, optimization
- Prep: MongoDB Data Modeling Path (~4.25 hr)

### Associate Atlas Administrator ($150, 120 min) — GA
- Validates: designing, operating, managing Atlas deployments — security, monitoring, performance, upgrades
- Two path versions: current (13 hr) and v1 (still valid for enrolled learners); both unlock 50% discount
- Note: free beta exam available through July 14, 2026 — verify pricing before advising customers

### Associate DBA Self-Managed ($150) — REVISION IN PROGRESS
- Old exam retired; beta sign-up open at learn.mongodb.com/pages/mongodb-associate-database-administrator-exam
- Start the 13-hr DBA path now for a 50% discount when the new exam launches

## Exam Administration
- Proctoring: ProctorU (switched from Examity April 2024), 24/7
- Retake policy: 15-day cooling-off; retakes $150 full price (50% discount applies first attempt only)
- Rescheduling: free up to 24 hours before
- Accommodations: extended time for disabilities or non-English speakers; request 72 hr advance at certification@mongodb.com
- Score: pass/fail + domain breakdown; cut score not published
- Recertification: no fixed expiry published as of 2026-06-16; check learn.mongodb.com/courses/program-guide

## Skill Badges (Free Micro-Credentials, introduced Feb 2025)
- Format: 60–90 min content + 10-question assessment; free; Credly badge upon passing
- Catalog (2026-06-16): MongoDB Overview, MongoDB Basics for Students, Data Modeling series (4 badges), Indexing Design Fundamentals, Query Optimization, Fundamentals of Data Transformation, Search Fundamentals, Vector Search Fundamentals, Vector Search Performance, Building GenAI Apps (7.5 hr path), Deploying and Evaluating GenAI Apps

## ILT Courses

| Course | Content | Prerequisite |
|--------|---------|--------------|
| MDB100 | Atlas setup, document model, CRUD, security | None |
| MDB200 | Indexing, profiling, logs, metrics, Search/Vector intro | MDB100 |
| MDB300 | Replication, sharding, backup, cluster architecture | MDB100+200 |
| DEV400 | Advanced developer topics | MDB100-300 |
| OFA400/500 | Atlas Admin / Atlas API (8 hr each) | — |

- Delivery: virtual (Zoom + Instruqt); private for 7+ learners
- Precision Learning Programs (PLP): 20+ learner cohorts with tracking and ROI reporting

## Academic & Partner Programs
- **Students**: GitHub Student Developer Pack → $50 Atlas credit + free exam per completed path
- **Educators**: $500 Atlas credit + free certifications after completing Developer or DBA path; academia@mongodb.com
- **Partners/SIs**: No-cost certification workshops; CPE credits (4.8 NASBA) were offered via Carahsoft for a specific 2025 government-sector series only — not a standing program benefit; confirm before citing

## TAM Positioning Playbook
1. New team: Skill Badges (MongoDB Overview + Data Modeling) → role Learning Path → 50% discounted exam ($75) → ILT if needed
2. Validate proficiency: Developer → Associate Developer; Atlas/ops → Atlas Administrator; DBA → wait for revised exam; architects → Data Modeler
3. Evaluator with minimal time: MDB100 (1 day, no prerequisites)
4. Large teams (20+): Precision Learning Program
5. Exam failure: 15-day wait; review domain breakdown; targeted Skill Badges or ILT before retake

## Common Gotchas
- Associate DBA exam under revision (2026-06-16) — do not register customers; recommend path + beta sign-up
- Atlas Admin Path has two versions; direct new learners to current path
- Retakes cost full $150; the 50% path-completion voucher is first-attempt only
- Each language variant of the Associate Developer exam is a separate $150 purchase
- CPE credits from partner workshops are event-specific, not a standing benefit
