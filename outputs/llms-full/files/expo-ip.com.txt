									 Mit Expo-IP können beliebig viele Mitarbeiter gleichzeitig an einem Event arbeiten. Somit können umfangreiche Ausstellungen und Veranstaltungen in kurzer Zeit im Team realisiert werden. Expo-IP kann auf Deutsch und Englisch bedient werden.								
					
						
				
					 So viel Platz wie Sie benötigen 
						
									Mit einer Expo-IP Lizenz kann eine unbegrenzte Anzahl von Messeständen oder -hallen erstellt werden. Für kleinere Veranstaltungen gibt es eine günstige, auf 8 Messestände beschränkte Lizenz.
