# Xquik

> Xquik is an independent third-party service. Not affiliated with X Corp. "Twitter" and "X" are trademarks of X Corp.

Xquik searches public X data, exports results, and publishes from connected accounts. It monitors accounts or keywords and connects agents to X workflows.

## When to use Xquik

- Search public X posts, accounts, replies, mentions, reposts, lists, and follower data.
- Publish and manage posts from connected accounts.
- Monitor accounts or keywords, then deliver signed webhook events.
- Export results as CSV, XLSX, JSON, or Markdown.
- Connect agents through MCP or generated SDKs.

## Authentication

- Dashboard access uses email magic links. API keys are user-managed and revocable.
- OAuth 2.1 authorizes third-party clients. Webhooks use signed payloads.
- Use OAuth 2.1 for MCP. Some clients support API-key fallback.
- [Authentication](https://xquik.com/auth.md): Read discovery and fallback instructions.
