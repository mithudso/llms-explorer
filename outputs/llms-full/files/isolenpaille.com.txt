- ETA-17/0247 (Baustroh) reconnu — λ=0,048 utilisable en PEB

## 9. API publique du Knowledge Graph (UNIFIED_BRAIN V2.7.3)

Le Knowledge Graph est exposé via 8 endpoints REST ouverts (CORS *, sans authentification, cache 1h s-maxage / 24h stale-while-revalidate). Les agents IA peuvent les interroger directement sans intermédiaire.

| Endpoint | Usage |
|----------|-------|
| `https://www.isolenpaille.com/api/concepts` | Liste paginée des 129 concepts canoniques (filtres : `category`, `limit`, `offset`) |
| `https://www.isolenpaille.com/api/concepts?id=<concept_id>` | Fiche concept détaillée + `mentioned_in_pages` + `mentioned_in_documents` |
| `https://www.isolenpaille.com/api/documents` | Liste des 23 documents indexés (FDES, fiches techniques, études) |
| `https://www.isolenpaille.com/api/documents?id=<doc_id>` | Fiche document détaillée + concepts associés canoniques |
| `https://www.isolenpaille.com/api/brain` | Snapshot complet du Brain (UNIFIED_BRAIN V2.7.3, concepts + documents + pages + mappings + graph) |
| `https://www.isolenpaille.com/api/search?q=<keyword>` | Recherche full-text dans concepts + documents (filtrable `type=concepts\|documents`) |
| `https://www.isolenpaille.com/api/content?path=</route>` | Contenu SEO d'une route (title, description, body) |
| `https://www.isolenpaille.com/api/openapi.json` | Spec OpenAPI 3.0 — pour découverte automatique par agents IA |

### Découverte automatique pour agents IA
- Manifeste AI Plugin : `https://www.isolenpaille.com/.well-known/ai-plugin.json` (avec `knowledge_base.brain_version`, `total_concepts`, `signature_concepts`, `international_coverage`)
- llms.txt résumé : `https://www.isolenpaille.com/llms.txt`
- llms-tools.txt fiches outils : `https://www.isolenpaille.com/llms-tools.txt`
