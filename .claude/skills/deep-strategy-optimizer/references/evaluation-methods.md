# Evaluation methods for trading strategies and indicators

Every way this skill knows to evaluate a strategy or an indicator, one row per method, grouped into nine families. Built 2026-11-07 from the v1.1.1 passes, the solmargintrader test bed (read-only), the trading-and-investing skill, and web sources opened during the build. The list is best-effort, not provably exhaustive; known gaps are at the end.

**Columns.** *Applies to*: strategy (positions and P&L), indicator (a signal scored against outcomes), or both. *Pass ID*: the pass that runs the method; `metric only` = computed for the report's metric panel, no pass (no defect/fix semantics on its own); `→ XX-nn (merged)` = same input series and same statistic as another method, so it shares that pass; `unverified` in *Source* = the method was named but no source was opened in this build.

**Thresholds.** Every numeric threshold or minimum sample is cited, or labelled `heuristic (author-set)`, or `none established`. Repo paths are relative to the solmargintrader test bed; `t&i` = the trading-and-investing skill's references; `v1` = this skill's v1.1.1 passes (`legacy-mapping.md`).
